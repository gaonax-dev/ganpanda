## 1. 발명의 명칭 (안)
사진 기반 사인물 협업에서 **게시물(사인물 영역) 또는 사진 지점에 앵커된 수신자 지정 대화 채널을 마지막 상태 요약으로 표시**하는 방법 및 시스템

## 2. 배경기술과 문제
- 간판 제작은 제작자·디자이너·시공·고객이 **건물 사진 위의 특정 자리**를 두고 대화합니다. 지금은 카카오톡·전화·메일로 "거기 그 간판", "왼쪽에서 두 번째 창 위"처럼 말로 위치를 가리켜 오해·누락·재방문이 잦습니다.
- 기존 도구(피그마 코멘트, 구글 문서 코멘트, 사진 마크업 앱)는 **좌표에 핀을 꽂는 코멘트**는 제공하지만 ① 대화 대상이 "실측 치수·사양·견적을 가진 **사인물 객체**"가 아니고, ② 코멘트가 **원근이 있는 사진 위의 벽면 좌표계**와 연결되지 않으며, ③ 수신자별 가시성(특정인에게만 보이는 코멘트)과 ④ 공간 위 **마지막 상태 요약 표시**가 결합되어 있지 않습니다.

## 3. 해결 수단 (발명의 구성)
1. **앵커**: 대화 채널(스레드)이 (a) 사진의 한 지점(원본 px 좌표) 또는 (b) **사인물 객체**(사진 위 외곽선 사각형·다각형, 실측 mm 치수·사양·견적을 가진 데이터 객체)에 묶인다. 객체에 묶인 채널은 객체가 **이동·연결(sameAs)·다른 사진에 복제**되어도 따라간다(채널 id = 원본 객체 id).
2. **수신자 지정 가시성**: 채널에 받는 사람(`to`)을 둘 수 있고, 지정되면 **보낸 사람·받는 사람·프로젝트 소유자**에게만 채널과 알림이 보인다. 비우면 모두에게. 가시성은 동기화 문서(CRDT)에 저장된 채널 속성과 열람자의 이름·역할로 **클라이언트에서 판정**한다.
3. **마지막 상태 요약 표시**: 사진 위 말풍선에는 그 채널의 **마지막 상태**만 — 해결됨 표식 또는 "작성자: 마지막 메시지 요약(첫 줄, N자)" — 보이고, 전체 대화는 누를 때 연다. 안 읽은 수는 말풍선 안에.
4. **역할별 쓰기 경로**: 문서 편집 권한이 없는 열람자(고객)도 서버 API를 통해 채널을 만들 수 있고, 서버가 동일 구조로 CRDT 문서에 기록한다.
5. **원근·3D와의 결합**: 채널이 붙은 사인물은 같은 데이터에서 실측 치수·견적·3D 합성(실사 주/야간)이 나오므로, 대화의 대상이 **보이는 결과물과 동일 객체**다. 3D 합성 화면에서도 같은 말풍선을 눌러 대화할 수 있다.

## 4. 효과
- 위치·대상 오해 제거(대화가 객체·좌표에 고정), 수신자 지정으로 역할 간(디자이너↔제작, 제작↔고객) 사적인 메모와 공개 소통 분리, 요약 표시로 사진 한 장에서 **모든 자리의 진행 상태**를 한눈에 파악, 고객도 로그인 없이 참여.

## 5. 청구항 초안 (변리사 검토용)
**[독립항 1 — 방법]** 사진 위 사인물 협업 시스템에서 수행되는 방법으로서,
(a) 건물 사진 위에 외곽선으로 정의되고 실측 치수 및 사양 정보를 갖는 사인물 객체를 저장하는 단계;
(b) 상기 사인물 객체 또는 상기 사진의 좌표 지점을 앵커로 하는 대화 채널을 생성하고, 상기 채널의 식별자를 상기 앵커 객체의 식별자 또는 상기 좌표와 연관시켜 공유 문서에 저장하는 단계;
(c) 상기 채널에 수신자 식별 정보를 선택적으로 저장하는 단계;
(d) 열람자의 식별 정보 및 역할에 기초하여, 수신자 식별 정보가 있는 채널은 보낸 사람·수신자·소유자에게만 표시하고 없는 채널은 모든 열람자에게 표시하도록 판정하는 단계;
(e) 상기 사진 위의 앵커 위치에 상기 채널의 마지막 메시지 요약 또는 해결 상태만을 포함하는 말풍선을 표시하고, 선택 시 전체 대화를 표시하는 단계를 포함하는 방법.

**[종속항 예]**
- 2. 상기 사인물 객체가 다른 사진의 객체와 동일 사인물로 연결(sameAs)될 때 하나의 채널이 양쪽 앵커에 표시되는 방법.
- 3. 상기 말풍선이 사진 원근으로부터 복원한 3차원 벽면 위에 합성된 사인물 영상 위에도 동일 앵커로 표시되는 방법.
- 4. 문서 편집 권한이 없는 열람자가 서버 API를 통해 채널을 생성하고, 서버가 상기 공유 문서(CRDT)에 동일 구조로 기록하는 방법.
- 5. 상기 요약이 첫 줄 N자 이하로 절단되고 작성자가 열람자 본인이면 '나'로 치환되는 방법.
- 6. 수신자 후보가 현재 접속자·대화 참여자·기존 채널 작성자/수신자로부터 자동 구성되는 방법.
- 7. 수신자 지정 채널의 메시지 알림이 가시 대상에게만 전달되는 방법.
- **[독립항 — 시스템/저장매체]** 위 방법을 수행하는 서버·클라이언트 시스템 및 프로그램을 기록한 매체.

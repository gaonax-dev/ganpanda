# 제품 비전

## 요약
간판다는 **간판 제작자와 고객이 건물 사진 위에서 사인물을 함께 정하고 견적까지 내는 협업 도구**입니다.
웹으로 먼저 출시하고, 이후 Tauri 데스크톱 앱으로 냅니다.

## 핵심 개념
- **세 화면 모두 무한 캔버스**입니다.
  1. **사진 보드** — 사진 한 장이 하나의 "구역"입니다. 사진 위에 사인물 영역(사각·원형, 이후 AI 자동 분리)을 표시하고, 오브젝트마다 치수·종류·시트를 정하며 코멘트와 카톡형 대화로 소통합니다. 결과물을 눈으로 보며 소통하는 곳입니다.
  2. **사인물 리스트** — 모든 사인물을 원근 보정해 실제 mm 축척으로 펼친 전개도입니다. 최종 결과물이 모이는 곳이고, **견적은 여기서 산출**합니다.
  3. **UV 뷰** — 디자인 파일(한 파일에 이미지가 여러 개일 수 있음)에서 이미지를 골라 사인물 면에 맞춰 넣습니다.
- **사인물 종류**: 간판 종류(보드 / 채널)와 시트 종류(복수 선택)를 고릅니다.
- **실측 판독**: 사용자가 입력한 치수가 사진과 맞지 않으면 경고합니다. → [measurement.md](../features/measurement.md)
- **한 장으로 결정하기** (2026-10-14 추가): 세 화면은 제작자의 작업 공간이고, 고객에게는 **제안 링크 하나**(실사 주/야간 · 치수 · 금액 · 질문 · 승인)로 보입니다. 간판집의 수주와 분쟁 없는 확정, 고객의 미리 보기·가격·공유 결정이라는 니즈가 여기서 만납니다. → [roadmap.md](roadmap.md) 6차

## 원칙
- **AI 최소화, 결정론적 처리**: 원근·치수·견적은 수학과 규칙으로 계산합니다. AI는 영역 자동 분리(브라우저 내장 SAM)처럼 "처음 한 번 인지"하는 데만 씁니다. 비용이 들지 않고, 결과가 항상 같으며, 실측 견적에 쓸 수 있습니다.
- **오프라인에서도 동작**: 서버가 없거나 끊겨도 작업이 가능하고, 다시 연결되면 자동으로 합쳐집니다.
- **Tauri 호환**: 화면은 외부 CDN이나 서버 렌더링에 의존하지 않습니다(폰트 번들 포함).

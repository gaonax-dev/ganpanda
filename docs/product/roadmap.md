# 로드맵

## 요약
사용자가 정한 5단계 순서입니다(2026-10-13). 각 단계의 세부 범위는 시작할 때 확정하고 여기에 적습니다.

| 단계 | 목표 | 상태 |
|---|---|---|
| 기반 | Svelte 재구성, 무한 캔버스, 사진 보드, 실측 판독, 전개도·견적 골격, 동기화 서버 | 구현됨 |
| **1차** | 간판 제작 커뮤니케이션 역할을 충실하게 | 진행 예정 |
| 2차 | 자동 견적이 가능하도록 준비 | 계획 |
| 3차 | 일러스트레이터 파일을 이미지 소스로 직접 변환 + 소스 히스토리 | 계획 |
| 4차 | 입체 간판 (글자를 3D로) | 계획 |
| 5차 | 결과물을 바로 확인하는 실사 렌더링 | 계획 |

## 기반 단계 — 구현됨
- 사진 보드: 사진 업로드·이동, 사각·원형 영역, 원근 모서리 편집 → [photo-board.md](../features/photo-board.md)
- 실측 판독: 기준 영역, 자동 추정, 12% 경고 → [measurement.md](../features/measurement.md)
- 오브젝트별 대화·코멘트 (현재 기기 내 저장) → [communication.md](../features/communication.md)
- 사인물 리스트 전개도와 견적 → [sign-list-quote.md](../features/sign-list-quote.md)
- 동기화 서버 (`server/`): 실시간 동기화, 저장, 접속자 표시, 에셋 → [server/api.md](../server/api.md)

## 1차 — 커뮤니케이션 (범위 확정 전, 후보)
확정되지 않았습니다. 시작할 때 사용자와 범위를 정하고 이 절을 고칩니다.
- 앱 ↔ 동기화 서버 연결 (실시간 공동 편집, 연결 상태 표시)
- 초대 링크로 고객 참여 (로그인 없이 이름만)
- 접속자 표시 (누가 보고 있는지, 커서)
- 계정 로그인 (카카오 · 구글 · 이메일) → [decisions.md](decisions.md)
- 요금제 제한 (용량·동시접속), 결제는 제외 → [pricing.md](pricing.md)
- 그 밖의 후보: 오브젝트 상태(요청 → 검토 → 확정), 안 읽은 메시지 표시, 사진 위 위치 코멘트, 모바일 터치 최적화, SAM 호버 영역 분리

## 2차 — 자동 견적 준비 (계획)
- 단가표 관리 (현재 예시값: `src/lib/core/catalog.ts`)
- 견적 규칙 고도화 (채널 글자수 자동 산출, 설치비·운반비, 부가 옵션)

## 3차 — 일러스트레이터 파일 변환 + 소스 히스토리 (계획)
- .ai 파일에서 이미지 소스를 직접 추출, 한 파일 속 여러 이미지 분리
- 오브젝트에 연결된 디자인 소스의 버전 기록
- UV 뷰에서 소스를 사인물 면에 매핑 → [uv-view.md](../features/uv-view.md)

## 4차 — 입체 간판 (계획)
- 글자 윤곽 → 3D 채널 글자 → [render-3d.md](../features/render-3d.md)

## 5차 — 실사 렌더링 (계획)
- 사진 속에 실제처럼 합성 (주간 그림자, 야간 LED 발광) → [render-3d.md](../features/render-3d.md)

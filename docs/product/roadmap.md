# 로드맵

## 요약
사용자가 정한 5단계 순서입니다(2026-10-13). 각 단계의 세부 범위는 시작할 때 확정하고 여기에 적습니다.

| 단계 | 목표 | 상태 |
|---|---|---|
| 기반 | Svelte 재구성, 무한 캔버스, 사진 보드, 실측 판독, 전개도·견적 골격, 동기화 서버 | 구현됨 |
| **1차** | 간판 제작 커뮤니케이션 역할을 충실하게 | 1-1 완료, 1-2a 완료, 1-2b 진행 예정 |
| 2차 | 자동 견적이 가능하도록 준비 | 계획 |
| 3차 | 일러스트레이터 파일을 이미지 소스로 직접 변환 + 소스 히스토리 | 계획 |
| 4차 | 입체 간판 (글자를 3D로) | 계획 |
| 5차 | 결과물을 바로 확인하는 실사 렌더링 | 계획 |

- 동기화 서버 (`server/`): 실시간 동기화, 저장, 접속자 표시, 에셋 → [server/api.md](../server/api.md)

## 1차 — 커뮤니케이션 (범위 확정 2026-10-13)

### 포함
| 묶음 | 내용 |
|---|---|
| 1-1 실시간 연결 | **구현됨** — 앱 ↔ 동기화 서버 연결(실시간 공동 편집, 연결 상태 표시), 에셋 서버 업로드, 접속자 표시(누가 보고 있는지, 커서) → [architecture/sync.md](../architecture/sync.md) |
| 1-2 계정·권한·요금제 | 1-2a **이메일 매직링크 로그인 — 구현됨** → [features/accounts.md](../features/accounts.md) / 1-2b 프로젝트 소유 계정·**초대 링크마다 권한 선택**(보기·대화만 / 편집 가능, 서버에서 강제) / 1-2c 요금제 제한(용량, 계정 합계 동시접속) → [pricing.md](pricing.md) / 1-2d 카카오·구글 로그인 |
| 1-3 소통 | 안 읽은 메시지 표시·새 메시지 알림, **사진 위 위치 코멘트**(핀), **대화에 사진·파일 첨부** |
| 1-4 편의 | 실행 취소·다시 실행(내 편집만 되돌림), **카카오톡 공유**(초대 링크, 미리보기 이미지·제목) |
| 1-5 AI 영역 분리 | SAM 호버 영역 분리 (브라우저 내장) |

### 제외 (이번 1차에 넣지 않음)
- 사인물 상태 흐름(요청 → 검토 → 확정)
- 모바일 터치 최적화 — 단, 카카오톡으로 받은 링크는 대부분 휴대폰에서 열립니다. 1차에서는 휴대폰에서 "보기·대화"가 깨지지 않는 수준만 확인합니다.

### 진행 순서
1-1 → 1-2 → 1-3 → 1-4 → 1-5. 각 묶음은 TDD로 진행하고 끝날 때마다 브랜치를 머지합니다.

### 사용자가 준비해야 하는 것 (1-2, 1-4 시작 전)
- Cloudflare 계정 (배포)
- 서비스 도메인 (OAuth 리디렉션·이메일 발송·공유 링크에 필요)
- 카카오 디벨로퍼스 앱: REST API 키(로그인), JavaScript 키(카카오톡 공유), 리디렉션 URI 등록
- 구글 OAuth 클라이언트 ID·비밀
- 이메일 발송 설정 (도메인 인증)

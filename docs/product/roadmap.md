## 6차 — 한 장으로 결정하기: 제안 링크 + 승인 (계획 2026-10-14)

### 왜 (니즈)
운영 첫날 지표(계정 1·초대 0)는 "써 보고 떠남"이 아니라 "아직 아무도 안 옴"이었고, 그래서 불만(입구·빈 화면)이 아니라 **양쪽의 니즈**에서 다시 출발했습니다.

| 누구 | 니즈 |
|---|---|
| 간판집 | **수주** — 견적만 받아 가는 고객을 잡아야 한다. 고객이 미루는 이유는 "어떻게 보일지 모르겠다", "이 가격이 맞나" |
| 간판집 | **확정 뒤 분쟁 없음** — 제작 후 "생각한 게 아닌데", "크기가 왜 이래요"가 가장 큰 손실. 무엇을 합의했는지 기록 |
| 간판집 | **왔다 갔다 줄이기** — 실측 방문, 카톡에 흩어진 사진·시안·수정 요청을 한곳에서 |
| 고객 | **내 가게에 달린 모습을 미리**, 특히 밤에 |
| 고객 | **얼마인지 바로**, 다른 곳과 비교 |
| 고객 | **동업자·배우자·건물주에게 보여 주고 결정** — 휴대폰으로 |

양쪽 니즈가 모이는 곳은 **"한 장으로 결정하기"**입니다. 지금의 간판다는 제작자용 도구이고, 고객에게 보이는 결과 화면과 승인이 빠져 있습니다(1차에서 제외했던 "상태 흐름"이 사실 핵심 니즈).

### 무엇을
간판집이 고객에게 보내는 **제안 링크 하나**:
> 당신 가게 사진 위에 간판이 이렇게(주간/야간) 달립니다 · 사인물 목록과 치수 · 총 금액 · 궁금한 점 묻기 · **[이걸로 할게요]**

| 묶음 | 내용 | 상태 |
|---|---|---|
| 6-1 제안 페이지 | 휴대폰 우선, 로그인 없음(초대 링크 권한 그대로). 실사 주간/야간 이미지, 사인물 목록·치수, 견적 합계(세부는 펼침), 질문(기존 대화·핀 재사용). 카카오톡·문자로 보내기 좋은 링크(미리보기 이미지·제목). 다른 사람에게 그대로 전달 가능 | 계획 |
| 6-2 승인·기록 | [이걸로 할게요] → 승인 시점의 **사진·사인물·치수·디자인·금액 스냅샷**을 버전으로 저장, 승인자 이름·시각 기록. 이후 변경은 새 버전 → 재승인. 간판집에 알림 | 계획 |
| 6-3 제안 만들기 | 보드에서 [제안 보내기] 한 번으로 실사 이미지 생성·링크 발급. 사인물 분류·치수·금액이 비어 있으면 안내 | 계획 |
| 6-4 입구 | 간판집 쪽 입구인 카카오 로그인(운영 키 등록) → 그다음 | 코드 완료, 키 대기 |

### 하지 않을 것 (이번에는)
- 결제, 계약서·전자서명, 여러 시안(A안/B안) 비교 — 승인이 먼저 돌아간 뒤 판단
- 보드 자체의 모바일 편집 — 고객은 제안 페이지만 쓰면 되므로 보기·대화·승인만 휴대폰 대응

### 순서와 검증
6-1 → 6-2 → 6-3 → 6-4. TDD. 끝나면 **간판집 5곳 직접 방문**(사용자): 그 가게 사진으로 제안 링크를 만들어 고객에게 보내 보고, 고객이 결정을 미루는 진짜 이유를 듣는다. 현장에서 들은 니즈가 이 계획과 다르면 현장이 우선.

## 7차 — 카메라 솔버 (사진별 카메라 설정, 2026-10-14)
사용자: "사인물로 기준선을 잡는 건 복합적인 문제가 있다. fSpy 처럼 3차원 피봇과 x y z 중 두 방향에 2개의 라인으로 평가하는 방식과 기준 길이 선을 넣는 방식… AI 가 자동 추적하고 사용자가 다시 제어."

| 묶음 | 내용 | 상태 |
|---|---|---|
| 7-1 솔버 | 축 선 두 쌍(+깊이) · 원점 · 기준 길이 → 소실점 → 초점거리(직교) → 회전 → 위치 → 벽면. 제3 소실점으로 주점(잘라낸 사진). 합성 카메라로 1px 검증 | **구현됨** |
| 7-2 카메라 창 | 사진 위 핸들 끌기 + 돋보기, AI 축 선 자동 제안(허프) + 모서리 붙이기, 경고·결과 실시간, 적용은 사진에 저장 | **구현됨** |
| 7-3 존 = 벽면 | 존마다 평면(정면·옆면), 사인물은 자기 존의 평면으로 실측·실사 | 계획 |
| 7-4 EXIF | 휴대폰 JPEG 의 초점거리로 정면 사진의 f 확정, 렌즈 왜곡 k₁ | 계획 |

- 사인물에서 기준선(`refH/refV`)과 기준선 패널·조정 창은 제거. 카메라가 없을 때만 "치수 입력 첫 사인물" 규칙으로 대신.
- fSpy 는 GPL — 코드는 쓰지 않고 수식에서 직접 구현(라이선스 영향 없음) → [features/measurement.md](../features/measurement.md)

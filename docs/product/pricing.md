# 요금제

## 요약
기본은 무료이며, **저장 용량**과 **동시접속 인원**으로 구분합니다.

## 상태
계획 — 1차(1-2)에서 구현합니다. 코드에 아직 반영되지 않았습니다.

## 요금제

| 요금제 | 월 요금 | 저장 용량 | 동시접속 |
|---|---|---|---|
| 무료 | 0원 | 50MB | 3명 |
| 스타터 | 50,000원 | 2GB | 5명 |
| 프로 | 100,000원 | 10GB | 10명 |

## 규칙 (합의됨)
- **동시접속은 계정 전체 합계**입니다. 한 계정의 모든 프로젝트에 동시에 접속한 인원을 합쳐 셉니다.
- 초대 링크로 들어온 고객(로그인 안 함)도 인원에 포함됩니다.
- **결제는 이번 범위에서 제외**합니다. 제한과 업그레이드 안내만 만들고, 요금제 변경은 관리자가 수동으로 합니다. 결제 연동은 사업자 등록 후 진행합니다.

## 구현 방식
- **용량**: 에셋 업로드·다운로드는 `?project=<id>` + 자격(세션 또는 초대)이 필요합니다(viewer 도 대화 첨부를 위해 업로드 가능). 사용량은 **프로젝트 소유 계정**의 `account_assets`(계정, 에셋, 크기)에 쌓이고 같은 에셋은 한 번만 셉니다. 한도 초과 시 `413 {error:'storage_limit', limitBytes, usedBytes}`.
- **동시접속**: 계정마다 Durable Object `Account`가 좌석을 셉니다. 좌석 키 = 사람(로그인 = 계정 ID, 초대 손님 = 브라우저 고유 `guest` ID). 같은 사람의 탭 여러 개 = 1석, 계정의 모든 프로젝트 합산. 방 소켓이 열릴 때 좌석을 받고(초과면 `429 {error:'seat_limit', limit, used}`), 닫히면 반납, 90초 이상 갱신이 없으면 자동 반납(서버 비정상 종료 대비).
- 한도 초과 시 앱은 업로드 실패 안내 / 입장 불가 안내와 함께 업그레이드를 안내합니다(결제 미구현).

## 미정
- 요금에 부가세 포함 여부
- 한도 초과 시 동작 세부 (용량: 업로드 차단 / 동시접속: 입장 거절 + 안내)
- 요금제를 내릴 때 이미 한도를 넘은 데이터 처리

# 요금제

## 요약
기본은 무료이며, **저장 용량**과 **동시접속 인원**으로 구분합니다.

## 상태
계획 — 코드에 아직 반영되지 않았습니다.

## 요금제

| 요금제 | 월 요금 | 저장 용량 | 동시접속 |
|---|---|---|---|
| 무료 | 0원 | 50MB | 3명 |
| 스타터 | 50,000원 | 2GB | 5명 |
| 프로 | 100,000원 | 10GB | 10명 |

## 규칙 (합의됨)
- **동시접속은 계정 전체 합계**입니다. 한 계정의 모든 프로젝트에 동시에 접속한 인원을 합쳐 셉니다.
- 초대 링크로 들어온 고객(로그인 안 함)도 인원에 포함됩니다.
- **결제는 이번 범위에서 제외**합니다. 제한과 업그레이드 안내만 만들고, 요금제 변경은 관리자가 수동으로 합니다. 결제 연동은 사업자 등록 후 진행합니다.

## 설계 방향 (제안, 구현 전)
- 계정마다 Durable Object 하나(Account)가 요금제·사용 용량·현재 접속자를 순서대로 처리합니다. 동시에 들어와도 한도를 넘지 않게 하기 위해서입니다.
- 접속자는 소켓이 아니라 사람 단위로 셉니다(같은 사람의 탭 여러 개 = 1명).
- 서버가 비정상 종료돼도 인원이 남지 않도록, 접속을 주기적으로 갱신하는 임대 방식으로 셉니다.
- 같은 파일을 다시 올리면 용량을 중복으로 세지 않습니다(에셋 ID = 내용 해시).

## 미정
- 요금에 부가세 포함 여부
- 한도 초과 시 동작 세부 (용량: 업로드 차단 / 동시접속: 입장 거절 + 안내)
- 요금제를 내릴 때 이미 한도를 넘은 데이터 처리

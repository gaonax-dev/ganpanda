간판다에서는 한울과 같은 **공급 단가표**(꼬리표 `알리다`, 적용일 2025-03-01)입니다 → [../features/supplier-prices.md](../features/supplier-prices.md).

## 분류 (group) 와 단위
- 출력: `UV 후렉스 출력`(소폭 2,100 / 장폭 3,050 + 고주파·타공·클램프), `UV 대형 후렉스 출력`(원단 폭 4,200/5,000), `라텍스 후렉스 출력`, `라텍스 현수막 출력`·`라텍스 텐트천 출력`(폭×길이 장당 + 1m 추가), `라텍스 대형 …`, `UV시트 출력`, `UV투명시트 출력`(레이어별), `라텍스시트 출력`, `솔벤시트 출력`, `수성미디어 출력`, `페트베너 …`·`미니베너 출력`·`투명 페트베너 출력`(수량 구간 장당), `UV 평판 출력`, `사각재단 / 돔보컷팅`, `소량 현수막 출력`, `대형 현수막 출력`, `후가공 마감 비용`, `대량 현수막 출력`.
- 제작: 프레임 간판은 헤베당(3헤베 기준) + `기본가격(1.8헤베)` 고정가(개), 돌출은 M당 + 기본 1.8M. 채널·스카시·레이저는 **글자 크기 구간별 자당**(unit 개, note "자당" — 단가 화면에 `원/자`). 트러스바 기본 3m(개) + 1m 추가. 갈바 전면·지주 m당. LED 전광판 모델×열×색 대당.
- 시트류 공통 추가금(UV 코팅 +3,000, LX +500, LX시트 +1,000, 사각재단 +1,000)은 시트 분류마다 추가금 품목.
- 샘플 기본 **직접 출력** 분류(연결 안 함): UV·라텍스 후렉스, UV 대형 후렉스, UV·UV투명·라텍스·솔벤 시트, UV 평판.

## 품목에 넣지 않은 것
- 가격이 "문의·상담·별도": 스텐 지주·스텐 전면 전부, 갈바 HQI 전면, 돔보 100개 이상, UV 평판 재단·후가공, LED 2단/3단, SMD 전광판, 특수채널 사진 쪽, 펄·하드펄·메탈 아크릴 레이저.
- 비율 할증(형식 밖): 갈바 채널 후광 +10%, 3D 채널 난이도 +10~20%, 3D 일체형 외부용 +10% / 고급형 +50%.
- 금액 미표기 추가금: LED 부착비·시트 작업·종이도안·도장비(캡 채널), 3D 채널 입체 높이 변경, 고무 스카시 수작업·한문.
- 예시 금액(채널 완조립 그림), 대량 현수막 m당 환산 단가.
- 전선 외부용 3m +3,000원/개(3D 채널) — 필요하면 추가금으로.

## 해석한 것 (확인 필요)
- 프레임 간판 `기본가격(1.8헤베)` = 1.8헤베까지 최소 금액으로 해석. 3D 에폭시·일체형의 조명시트/실사 "기본 10,000 / 15,000원"도 최소 금액으로 보고 비고에만.
- 3D 일체형: 제목은 "50각 이상 별도문의"인데 표에 50·55각 가격이 있어 그대로 넣음.
- 수량 구간 "5장, 10장…"은 "N장 이상". 발통 크기 단위는 mm 로 추정.
- 원본 중복: 까치발·보강 지지대 표(22~23면 = 25면)는 한 번만(`채널 트러스바`). 페트베너 60×180·현수막 나무 마감은 여러 표에 같은 값이라 원본대로 각각.
- 스텐 미러/헤어라인 후광 채널과 티타늄 후광(골드미러)은 원본상 가격이 같음.

## 페이지 공통 조건
하자 시 재출력·재작업만(크레인·인건비 없음), 후렉스 10폭 여유(110폭 → 이미지 100폭), UV 출력 영상 5℃ 이상 시공, 차량시트 10℃ 이상, 헤베 단가는 이미지 사이즈·3헤베 기준(대형 후렉스는 원단 폭, 로스비·운임 별도), 수성·합성지 실내 전용, 대량 현수막 같은 데이터·선입금, 열재단·접어미싱·나무미싱 무료, 갈바 채널 선입금 50%, 전광판 1년 무상 A/S(공장 입고), 까치발·부자재비 별도.

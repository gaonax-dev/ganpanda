# 좌표계와 단위

## 요약
좌표가 섞이면 원근·치수가 틀어집니다. 데이터에 저장하는 값의 단위는 아래 표를 따릅니다.

| 대상 | 단위 | 원점·방향 |
|---|---|---|
| 오브젝트 영역 (`quad`, `polygon`) | 사진 **원본 픽셀** | 사진 좌상단, x 오른쪽, y 아래 |
| 치수 (`widthMm`, `heightMm`) | **mm** | |
| 사진 보드 위치 (`Photo.x, y, width`) | 보드 world 단위 | 사진 기본 표시 폭 1200 |
| 사인물 리스트 위치 (`listX`, `listY`) | **mm** (world 1 = 1mm) | |
| 화면 | CSS px | `screen = world × zoom + (x, y)` (`viewport.ts`) |

## 원근 변환
- 사각 영역 `quad`의 순서는 항상 **좌상 → 우상 → 우하 → 좌하**입니다.
- 정면 보정: `quadToRect(quad, wMm, hMm)` → 사진 px를 정면 mm로 보내는 호모그래피
- 화면 표시: `cssMatrix3d(H)`로 `<img>`에 원근 변환을 그대로 적용합니다 (전개도).
- 찌그러진 사각형(세 점이 일직선)은 호모그래피 계산이 불가능합니다. 모든 호출부는 예외를 처리하고 대체 동작을 해야 합니다 (`isValidQuad`).

## 카메라 모델 (`homography.ts`)
- 초점거리 기본값: 장변 × `DEFAULT_FOCAL_RATIO`(0.75) — 스마트폰 26mm 환산 기준
- 주점(principal point)은 사진 중앙으로 가정
- 벽 좌표(3D 시뮬레이터): 원점 = 기준 사각형 좌하단, X 오른쪽, Y 위, +Z 벽 밖(카메라 쪽), 단위 mm

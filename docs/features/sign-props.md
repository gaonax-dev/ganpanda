# 간판 속성 · 프로젝트 컬러 (2026-10-31)

사용자: "현재 사인물 설정이 많이 복잡해 전문가들도 어지러울 거 같아. … 현재 오브젝트를 조합한 3d 뷰가 최상단에 놓인다. 하단에 배치버튼으로 레이아웃 조정(이때 위의 뷰어는 그대로 있고 내용만 레이아웃 용으로 변경 · 배치버튼 아래에 현재 구성된 내용을 단으로 보여준다. 프레임이 최하단 그 윗단에 프레임에 붙는 요소를 나열한다. 해당 요소를 클릭하면 뷰어에 단일 요소만 남기고 쓱사라지면서 화면에 클로즈업한다. 이때 배치버튼 구성 단들은 사라지고 해당 요소를 선택할 수 있는 고르기 버튼과 해당 사인물의 마지막에 글,그림,path(디자이너용), gltf(디자이너용) · 색상을 개별구성에서 선택하지 않고 전체 사인물이 공유해야함으로 … 프로젝트 컬러 메인컬러, 배경컬러, 포인트컬러 … 시트, 필름, 원단, 페인트 … 브랜드 코드 … 해당 컬러를 변경하면 전부 변경 · 프로젝트 컬러셋을 추가하면 복제는 기존의 컬러 구성과 연결을 받아서. 컬러셋 프로젝트 뷰어 디자인에 컬러셋 누르면 컬러 대화창" → "우선 설명한 부분만 화면에 구성하는 미니멀 전략으로 진행해줘".

## 간판 속성 (`ui/SignProps.svelte`, 사인물 설정 창 맨 위) — 구현됨 (미니멀)
- **3D 뷰어**(`ui/SignView3D.svelte`): 지금 구성 그대로 사인물 전체(입체 보기와 같은 `renderSpecOf` + `buildSign`), 돌려 보기. 치수·구성이 없으면 안내.
- **[배치]**: 뷰어 자리 내용만 배치 화면(정면도 편집기 `FrontEditor`)으로, [배치 끝]으로 3D.
- **단**(`sign-tiers`): 위에서 아래로 — 다른 구성 요소 위에 올린 시트 → 프레임에 붙는 것(채널·스카시·프레임 면 시트) → **프레임(맨 아래, `sign-el-frame`)**. 요소 = 이름 + 글자.
- **요소 클로즈업**(`data-mode=focus`): 요소를 누르면 뷰어가 사라지듯 바뀌며(줄어들며 사라짐 → 커지며 나타남) 그 요소만 — 채널은 키트 G 한 글자([channel-models.md](channel-models.md)), 그 밖·프레임은 사인물 3D 를 가까이. 단·[배치]는 숨고:
  - **[고르기]**: 채널 = 그림 카드(키트, 없으면 사진), 그 밖 = 세부 종류, 프레임 = 몸통 종류.
  - **색**: 면마다(채널 앞면·몸통·캡, 스카시 도색, 프레임 바탕·테) **프로젝트 컬러 칸**을 고른다. 칸에 색이 하나도 없으면 "프로젝트 컬러 정하기"(대화창)부터.
  - **[＋ 글] [＋ 그림]** (그 요소에 객체), **[＋ path] [＋ gltf]** 디자이너용 — 아직 준비 중(비활성).
  - [← 전체]로 돌아간다.
- 지금까지의 설정(치수·단면·옵션·시트·문구·견적)은 아래 **"세부 설정"**(`sign-detail`)에 **접혀 있다 — 누구나 접힌 채로 시작**(2026-10-31 사용자: "사인물 기본 정보 아래 내용 안보이게 해줘"), 펼치면 이 기기에 기억(`localStorage ganpanda.signDetail`). E2E 는 `helpers.openObjectSettings`/`openSignDetail` 이 펼쳐 예전 화면 테스트가 그대로 돈다.
- **패널의 [설정](상세정보)이 곧 이 3D 화면으로 들어오는 곳**(2026-10-31 사용자: "상세정보는 사인물 설정 3d로 나오는 곳이 된다") — 열면 3D 뷰어·단이 먼저 보이고, 아래 단추 줄의 [입체 보기 (3D)]는 따로 큰 창(PNG 저장·폰트 기준 폭 적용)으로 그대로 둔다.
- 휴대폰: 설정 창이 열려 있으면 보드의 실시간 3D 를 내린다(그래픽 화면이 둘이 되지 않게 — [../architecture/rendering-lod.md](../architecture/rendering-lod.md)).
- 테스트 `tests/e2e/signProps.spec.ts`.

## 프로젝트 컬러 (`core/projectColors.ts`, `ui/ProjectColorsDialog.svelte`) — 구현됨
- 프로젝트 설정 `colors`: **컬러셋** 여러 개 + 지금 셋(`active`). 셋 = **칸**(처음엔 메인·배경·포인트, [＋ 칸 추가]) — 칸마다 미리보기 색(컬러 피커), 색 이름(예: 앰버), 재료별 브랜드 코드(시트 `LX C3940` · 필름 · 원단 · 페인트 `PANTONE …`).
- 사인물 면은 칸을 가리킨다: `<면>System = '프로젝트'`(`PROJECT_SYSTEM`), `<면>Slot`, 그리고 3D·칩용으로 지금 색 `<면>Hex`·칸 이름 `<면>Code`·제작 코드 `<면>Ref`. **칸 색을 바꾸거나 셋을 바꾸면** 그 칸을 쓰는 모든 사인물·구성 요소를 한 묶음(되돌리기 한 번)으로 다시 적는다(`app.setProjectColors` → `refreshColorPatches`).
- **[＋ 컬러셋] = 지금 셋 복제** — 칸 id 가 같아 사인물 연결이 그대로 이어지고, 새 셋이 쓰인다. 셋 칩을 누르면 그 셋으로(모든 사인물 색이 바뀜).
- 여는 곳: 디자인 탭 막대 **[컬러셋]**(`colors-open`), 간판 속성의 색 칸.
- 테스트 `tests/unit/projectColors.test.ts`, `tests/e2e/projectColors.spec.ts`.

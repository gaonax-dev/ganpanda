# 일러스트레이터 왕복 (대지 스크립트)

사용자(2026-11-05):
- "사인물 카드를 일러스트레이터 대지로 배치해 넣을 수 있나? 그리고 일러스트 저장값을 가져와 사인물 카드에 넣을 수 있나?"
- "대지를 다시 구성한다는건 이후에 일러스트에서 내보내고 이것을 간판다에서 연결하는 악순을 피하려는 거지"
- "가장 나이스한건 일러스트 플러그인을 개발하고 우리 포맷을 일러스트에서 재구성하는 거야 … 물론 바로 일러스트 파일로 만들어 보내는 게 더 좋아"
- "현재는 최신버전"

## 요약
간판다 견적 탭 **[일러스트]**(`export-illustrator`)로 받은 스크립트(`.jsx`)를 일러스트레이터에서 실행하면, 지금 카드 배치 그대로 **사인물마다 대지**가 생깁니다. 대지 이름은 "이름 #사인물id"입니다. 디자인을 마친 뒤 같은 스크립트를 다시 실행하면 **[간판다로 보내기]**가 됩니다. 대지 순서대로 사인물 id 를 문서 XMP 에 적어 PDF 호환 `.ai` 로 저장합니다. 그 파일을 간판다 디자인 탭에 올리면 대지가 사인물에 **자동으로 연결**됩니다. 일러스트에서 하나씩 다시 연결하던 일이 없어집니다.

## 상태
구현됨 (2026-11-05). 실제 일러스트레이터에서는 아직 시험하지 않았습니다. 가짜 일러스트레이터 DOM 위에서 스크립트를 돌려 검증했습니다(`tests/unit/illustratorJsx.test.ts`).

## 왜 스크립트인가 (`.ai` 를 직접 만들지 않는 이유)
`.ai` 의 대지 정보는 어도비 비공개 데이터에 있습니다. 우리가 만든 PDF 는 일러스트가 PDF 로 엽니다. 한 페이지면 대지가 하나뿐이고, 여러 페이지면 배치가 일러스트가 정한 줄로 바뀝니다. 스크립트(ExtendScript)는 일러스트 안에서 대지를 정확한 자리·크기·이름으로 만들고 `.ai` 로 저장할 수 있습니다. 설치 없이 **파일 › 스크립트 › 기타 스크립트…** 로 실행합니다.

## 간판다 → 일러스트 (대지 만들기)
- 데이터(`core/illustrator.ts` `illustratorPackage`): 카드마다 `{id, name, x, y, w, h(mm, 카드 배치 — 왼쪽 위 카드가 원점), face(카드 사진 data URL), design}`. 디자인 소스가 **SVG 면 원본 SVG 글자 그대로**와 잘라낸 영역 비율, 그 밖(.ai·PDF·그림)은 잘라낸 영역 PNG.
- 스크립트 = `var GANPANDA_DATA = {…};` + `src/lib/illustrator/ganpanda.jsx`(`jsxWithData`). 파일 이름 "<프로젝트> 일러스트 대지.jsx".
- 일러스트 쪽(`ganpanda.jsx`, ES3): 새 문서(RGB, 전체 크기) → 카드마다 `artboards.add([left, top, right, bottom])`(mm → pt, 위가 +) · 이름 "이름 #id". 처음 대지는 지운다. 레이어 **간판다 사진**(맨 아래, 카드 사진을 넣고 묻은 뒤 잠금) · **디자인**(SVG 원본은 `createFromFile` 로 벡터 그룹을 들여와 잘라낸 영역이 대지에 맞게 키우고 대지 사각형으로 클리핑, 그 밖은 그림). XMP 짝을 적고 저장 창 → PDF 호환 `.ai`.
- **축척**(`illustratorScale`): 일러스트 대지·캔버스 한도(약 5,779mm) 때문에 전체가 5,500mm 이하면 1:1, 넘으면 1:10, 그래도 넘으면 1:100. 끝나면 알림에 축척.

## 일러스트 → 간판다 (보내기·자동 연결)
- 스크립트를 다시 실행했을 때 열린 문서에 "#id" 대지가 있으면 [간판다로 보내기]를 묻는다. 지금 대지 순서대로 id 를 `ganpanda:artboards`(네임스페이스 `http://ns.ganpanda.co.kr/1.0/`, "id|id||id" — 빈 칸은 간판다 대지가 아님)로 적고 같은 파일에 PDF 호환으로 저장. [아니요]면 데이터로 새 대지 문서.
- 간판다(`state.addSourceFile` → `linkArtboards`): `.ai`·PDF 를 올리면 pdf.js 로 문서 XMP(`getMetadata().metadata.getRaw()`)와 페이지 실제 크기(mm)를 읽는다(`design/convert.ts`).
  - **XMP 짝이 있고 페이지 수가 같으면** 그대로 사인물에 페이지 전체를 입힌다 — **수정본을 다시 올리면 새 디자인으로 바뀐다**(이전 것은 디자인 이력에 남아 되돌릴 수 있음). 없는 사인물 id 는 뺀다.
  - **짝 정보가 없거나 페이지 수가 다르면** 대지 크기로(`matchArtboards`: 1:1·1:10·1:100 중 가장 많이 맞는 축척, 2% 또는 3mm 안, 같은 크기는 순서대로). 이때는 **아직 디자인이 없는 사인물만** — 우연히 크기가 같은 다른 PDF 가 기존 디자인을 덮지 않게.
  - 알림 "대지 n개를 사인물에 자동으로 연결했습니다"(크기로 짝지었으면 "(대지 크기로 짝지음)").

## 알 수 없는 것 (실제 일러스트에서 확인 필요)
- 일러스트가 문서 XMP 를 PDF 호환 `.ai` 의 PDF 메타데이터로 그대로 쓰는지. 안 쓰면 대지 크기 짝맞춤으로 넘어간다.
- 클리핑·SVG 들여오기의 세부 동작(버전별). 실패하면 그 디자인만 빠지고 나머지는 계속한다(try/catch).
- `.ai`·PDF 디자인 원본을 벡터로 넣는 것은 아직 없음(그림으로 들어감).

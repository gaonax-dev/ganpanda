## 요약
간판다 **디자인 탭 [⇄ 디자인 싱크] › 일러스트레이터 › 보내기 [대지 받기 (zip)]**(2026-11-06 [design-sync.md](design-sync.md) — 앞선 디자인 탭 막대 [일러스트 대지 받기]는 대체됨)로 받은 zip 을 풀어 그 안의 스크립트(`ganpanda.jsx`)를 일러스트레이터에서 실행하면, 지금 카드 배치 그대로 **사인물마다 대지**가 생깁니다. 대지 이름은 "이름 #사인물id"입니다. 디자인을 마친 뒤 같은 스크립트를 다시 실행하면 **[간판다로 보내기]**가 됩니다. 대지 순서대로 사인물 id 를 문서 XMP 에 적어 PDF 호환 `.ai` 로 저장합니다. 그 파일을 간판다 디자인 탭에 올리면 대지가 사인물에 **자동으로 연결**됩니다. 일러스트에서 하나씩 다시 연결하던 일이 없어집니다.

## 일러스트 기준 파일 싱크 — 정의 (2026-11-06)
사용자: "일러스트 기준 파일싱크에 대해 정의한다. 사인물카드는 실측(사진), 2d(속성내용), 3d(속성내용 3d추가), 디자인(대지 이미지). 보내기는 위의 순서로 최종(3d제외) 이미지로 보낸다.
일러스트 스크립트는 크기별고 대지를 생성하고 레이어를 생성한다. 받은이미지(최종이미지), 디자인(일러스트에서 작성된 이미지), path(3d 변환용).
가져오기는 대지를 기준으로 디자인과 path를 가져오는데 디자인은 대지 이름별로 이미지로 변환해 사인물 카드에 바로 젹용한다. path는 대지 이름을 통해 사인물을 찾고 해당 구성물의 path에 사용자가 연결한다."

### 대지 이름 = "프로젝트명 #번호" (2026-11-06)
사용자: "대지 #id로 추적하고 프로젝트명+숫자 간단하게" → "번호 규칙은 1부터 새로생기면 증분 사라지면 영구결번".
- 번호 = 사인물의 고정 **대지 번호**(`SignObject.artNo`). 보낼 때 번호 없는 사인물에 **만든 순서대로**(같은 순간에 만든 것은 보드 카드 자리 위 → 아래, 왼쪽 → 오른쪽) 매기고 저장한다(`core/illustrator.ts artNumbers`).
- **1부터, 새로 생기면 증분, 지운 사인물의 번호는 영구결번** — 지금까지 매긴 가장 큰 번호를 프로젝트 설정 `artNoLast` 에 두고 그 다음부터. 복제로 번호가 겹치면 뒤의 사인물에 새 번호.
- 대지 이름 "테스트 매장 #3"(프로젝트명의 # 은 뺌), XMP 짝·묶음의 사인물 값도 번호. 받을 때 `artRef` 로 번호 → 사인물(예전 이름 "이름 #사인물id" 도 읽는다).
- 디자인을 내보내면 번호가 생기고, 간판다 사인물 카드 이름 앞에 작은 **#3 배지**(`card-artno`)가 붙는다 — 받기 검토 패널에도 "#3". 홈 프로젝트 카드는 이 수로 "디자인 진행 받음/보냄" → [projects-invites.md](projects-invites.md).
- 앞선 대지 이름 "사인물 이름 #사인물id" 는 대체됨.

## 왜 스크립트인가 (`.ai` 를 직접 만들지 않는 이유)
`.ai` 의 대지 정보는 어도비 비공개 데이터에 있습니다. 우리가 만든 PDF 는 일러스트가 PDF 로 엽니다. 한 페이지면 대지가 하나뿐이고, 여러 페이지면 배치가 일러스트가 정한 줄로 바뀝니다. 스크립트(ExtendScript)는 일러스트 안에서 대지를 정확한 자리·크기·이름으로 만들고 `.ai` 로 저장할 수 있습니다. 설치 없이 **파일 › 스크립트 › 기타 스크립트…** 로 실행합니다.

## 간판다 → 일러스트 (대지 만들기)
- 만들기: `src/lib/illustratorExport.ts` `exportIllustrator`(치수 있는 카드, 임시 크기 제외). 데이터(`core/illustrator.ts` `illustratorPackage`, version 2): 카드마다 `{id, name, x, y, w, h(mm, 카드 배치 — 왼쪽 위 카드가 원점), image(최종 이미지 images/<id>.png)}` (2026-11-06 — 앞선 face·design·parts 는 대체됨).
- 스크립트 = `var GANPANDA_DATA = {…};` + `src/lib/illustrator/ganpanda.jsx`(`jsxWithData`). 파일 이름 "<프로젝트> 일러스트 대지.jsx".
- 일러스트 쪽(`ganpanda.jsx`, ES3): 새 문서(RGB, 전체 크기) → 카드마다 `artboards.add([left, top, right, bottom])`(mm → pt, 위가 +) · 이름 "이름 #id". 처음 대지는 지운다. 레이어 **간판다 사진**(맨 아래, 카드 사진을 넣고 묻은 뒤 잠금) · **디자인**(SVG 원본은 `createFromFile` 로 벡터 그룹을 들여와 잘라낸 영역이 대지에 맞게 키우고 대지 사각형으로 클리핑, 그 밖은 그림). XMP 짝을 적고 저장 창 → PDF 호환 `.ai`.
- **축척**(`illustratorScale`): 일러스트 대지·캔버스 한도(약 5,779mm) 때문에 전체가 5,500mm 이하면 1:1, 넘으면 1:10, 그래도 넘으면 1:100. 끝나면 알림에 축척.

## 일러스트 → 간판다 (보내기·자동 연결)
- 스크립트를 실행하면 **[가져오기] · [내보내기] · [취소]** 단추 창(ScriptUI, 2026-11-07 "스크립트 버튼에 가져오기 내보내기 버튼으로 변경해줘" — 앞선 "간판다로 보낼까요?" 확인 창은 대체됨). 가져오기 = 간판다 → 일러스트(받은 폴더로 대지 만들기), 내보내기 = 일러스트 → 간판다 — 열린 문서에 간판다 대지(#번호)가 없으면 꺼짐. ScriptUI 가 없으면 예전 확인 창. [내보내기]: 지금 대지 순서대로 id 를 `ganpanda:artboards`(네임스페이스 `http://ns.ganpanda.co.kr/1.0/`, "id|id||id" — 빈 칸은 간판다 대지가 아님)로 적고 같은 파일에 PDF 호환으로 저장. [아니요]면 데이터로 새 대지 문서.
- 간판다(`state.addSourceFile` → `reviewArtboards`, 2026-11-06부터 **[디자인 싱크] › 받기 → 사진보드 검토 → [확정]** — [design-sync.md](design-sync.md)): `.ai`·PDF 를 올리면 pdf.js 로 문서 XMP(`getMetadata().metadata.getRaw()`)와 페이지 실제 크기(mm)를 읽는다(`design/convert.ts`).
  - **XMP 짝이 있고 페이지 수가 같으면** 그대로 사인물에 페이지 전체를 입힌다 — **수정본을 다시 올리면 새 디자인으로 바뀐다**(이전 것은 디자인 이력에 남아 되돌릴 수 있음). 없는 사인물 id 는 뺀다.
  - **짝 정보가 없거나 페이지 수가 다르면** 대지 크기로(`matchArtboards`: 1:1·1:10·1:100 중 가장 많이 맞는 축척, 2% 또는 3mm 안, 같은 크기는 순서대로). 이때는 **아직 디자인이 없는 사인물만** — 우연히 크기가 같은 다른 PDF 가 기존 디자인을 덮지 않게.
  - 바로 입히지 않고 연결·바뀜·새로 생김(짝 없는 대지 → 새 사인물로)·누락(파일에 없는 사인물 → 기존 유지/연결 해제)을 보여 주고 [확정]하면 입힌다(앞선 "자동 연결" 알림은 대체됨).

## 구성 요소 레이어 — 디자이너가 사인물 구성대로 작업 (2026-11-05, 대체됨 2026-11-06 → 위 "정의": 레이어는 받은 이미지·디자인·path 셋)
사용자(디자이너): "내가 디자이너야 사인물에 각각의 디자인이 연결되어야해 후렉스(인쇄) 위에 체널(입체), 스카시(입체+ 시트 또는 도색)의 구성이라면 일러스트 레이어를 생성하고 이걸 내보내서 자동으로 간판다에서 보여질 수 있게". 앞 질문: "일러스트 패스로 입체 사인물이 가능한가?"
- **만들기**: 사인물마다 레이어 "이름 #id" — 안에 하위 레이어 **"바탕 (인쇄) #id:frame"**(맨 아래, 바탕 디자인이 여기로) 와 구성 요소마다 **"<세부 종류> (입체) #id:구성요소id"**(밀어내는 종류 = 채널·스카시) · **"<세부 종류> (인쇄) #id:…"**(내용을 받는 평면 종류 = 시트). 내용을 안 받는 종류(조명·몰딩·지주)는 없음. 카드 사진은 맨 아래 잠긴 "간판다 사진" 레이어. 데이터 `parts`(`illustratorExport.ts`, 종류 모듈 `extrude`·`takesItems` 로 판단).
- **보내기**: [간판다로 보내기]가 .ai 저장에 더해, 내용이 있는 구성 요소 하위 레이어마다 그 레이어만 대지 크기의 임시 문서로 복제해 내보낸다 — **입체 = SVG(글자는 윤곽선 `SVGFontType.OUTLINEFONT`)**, **인쇄 = PNG(투명, 긴 변 약 2048px)** → base64 로 **"같은 이름.ganpanda"** 묶음(`{format: 'ganpanda-illustrator-bundle', items: [{sign, part, kind: svg|png, data}]}`).
- **간판다**(`state.applyIllustratorBundle`, `core/illustratorBundle.ts`): [디자인 싱크] › 일러스트레이터 › 받기로 `.ganpanda` 를 올리고 사진보드 검토에서 [확정]하면(2026-11-06) —
  - 바탕(frame) → 사인물 **바탕 디자인**(새 디자인 소스, 디자인 이력에 남음).
  - 구성 요소 → 그 구성 요소의 내용을 디자인 하나로 바꾼다(러프 글자·그림 → 디자인, ⌘Z): 사인물 크기 전체의 그림 객체, SVG 면 **`vector: true`**.
  - 없는 사인물·구성 요소는 건너뛴다. 묶음에 없는 사인물은 검토에서 누락으로 보인다.
- **입체**: 밀어내는 구성 요소(채널·스카시)의 벡터 그림은 3D 에서 **패스를 재료 층 두께만큼 밀어낸다** — `core/vectorShapes.ts svgShapes`(three `SVGLoader`, 채운 패스만·구멍 유지, 대지 → 사인물 상자 mm), `render/itemImages.ts loadItemVectors`, `core/render.ts composedOf`(letterItems `vectorId`), `sim/signs.ts channelGeometry`(`vectorShapes`·`vectorScale`, 글꼴 맞춤 없음). 조명(전광·후광)·마감(재료 층 도색·시트)은 글자 채널과 같다. 2D 보드·카드·견적 카드에는 SVG 그림으로. 시트의 벡터·그림은 평면.
- 디자이너가 지킬 것: 입체 레이어의 글자는 윤곽선(보내기가 자동), **선(획)은 면으로 확장**(선만 있는 패스는 입체가 안 되어 빠진다), 닫힌 패스.

## 실행 속도 — 그림은 폴더의 파일을 연결 (2026-11-05)
사용자: "일러스트에서 .jsx를 가져오는데 많은 시간이 걸린다" → (해독 개선·사진 묻기 뒤에도) "5분정도 걸린다. 차라리 이미지들을 따로 폴더에 넣고 연결하는게 좋을 거 같은데".
- 원인: 사진·디자인 그림을 base64 로 스크립트 안에 넣으면(28개 = 약 0.5MB) 일러스트의 오래된 스크립트 엔진(ExtendScript)이 푸는 데 몇 분.
- **이제 [일러스트 대지 받기] = zip**(`core/zip.ts zipStore` — 압축 없는 STORE, 라이브러리 없음): `ganpanda.jsx`(데이터 + 스크립트, 28개 = 약 17KB) + `images/<사인물id>.png`(최종 이미지, 2026-11-06 — 앞선 face.jpg·design.png|svg 는 대체됨). zip 안 이름은 **영문만**(윈도우 기본 압축 풀기에서 한글 이름이 깨지지 않게), 최상위 폴더 없이 — 풀면 zip 이름(프로젝트명) 폴더가 된다. 파일 이름 "<프로젝트> 일러스트 대지.zip".
- 스크립트는 자기 위치(`$.fileName` 의 폴더)의 `images/…` 를 **연결된 그림**으로 놓는다 — 풀기·묻기(embed) 없음. SVG 디자인은 벡터로 들여온다. 폴더에 없는 그림은 건너뛰고 "그림 n개를 찾지 못했습니다 — zip 을 풀고 그 폴더 안의 ganpanda.jsx 를 실행" 알림.
- 연결이므로 .ai 를 옮길 때는 images 폴더도 함께(또는 일러스트 연결 패널에서 묻기).
- 예전 형식(data URL)도 그대로 읽는다 — 그때만 "카드 사진을 넣을까요?"를 묻고 푼다(빠른 해독: 표·4글자 단위·덩어리).
- 실행: zip 을 풀고 **파일 › 스크립트 › 기타 스크립트…**(⌘F12 / Ctrl+F12)로 그 폴더의 `ganpanda.jsx`.

## 설치형 스크립트 — 폴더를 골라 (2026-11-05)
사용자: "가볍게 일러스트에 스크립트 설치하고 실행하면 폴더 선택가능하게 파인더 띄워주고 가는건".
- [디자인 싱크] › 일러스트레이터 › 보내기(`ui/DesignSyncDialog.svelte`, 2026-11-06 — 앞선 작은 창 `IllustratorExport.svelte` 는 대체됨): **[대지 받기 (zip)]**(`illustrator-download`) · **[설치용 스크립트 (간판다.jsx)]**(`illustrator-script`, 데이터 없는 스크립트) · 설치 안내.
- zip 에 **`ganpanda.json`**(패키지 데이터)을 더했다 — `ganpanda.jsx`(데이터 포함, 설치 없이 바로 실행)도 그대로.
- 설치: `간판다.jsx` 를 일러스트 스크립트 폴더(맥: 응용 프로그램 › Adobe Illustrator › Presets › ko_KR › 스크립트 / 윈도우: Program Files › Adobe › Adobe Illustrator › Presets › ko_KR › 스크립트)에 넣고 다시 켜면 **파일 › 스크립트 › 간판다**.
- 실행: 단추 창에서 [내보내기](간판다 대지 문서를 연 채) 또는 [가져오기] → **폴더 선택 창**(`Folder.selectDialog`) → 그 폴더의 `ganpanda.json` 을 읽어(`eval` — 간판다가 만든 데이터) 대지, 그림은 **그 폴더의 images/** 를 연결. 취소하면 아무것도 안 함, `ganpanda.json` 이 없으면 알림.

## 알 수 없는 것 (실제 일러스트에서 확인 필요)
- 일러스트가 문서 XMP 를 PDF 호환 `.ai` 의 PDF 메타데이터로 그대로 쓰는지. 안 쓰면 대지 크기 짝맞춤으로 넘어간다.
- 클리핑·SVG 들여오기의 세부 동작(버전별). 실패하면 그 디자인만 빠지고 나머지는 계속한다(try/catch).
- `.ai`·PDF 디자인 원본을 대지에 벡터로 넣는 것은 아직 없음(그림으로 들어감).
- 실제 일러스트에서 레이어를 다른 문서로 복제(`duplicate`)·임시 문서 내보내기·글자 윤곽선 SVG 가 기대대로인지(버전별).

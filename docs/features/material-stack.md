## 지금 있는 바탕
- **재료 층 모델**(`core/stack.ts`, 2026-10-21 스카시): 구성 요소 하나 = 뒤에서 앞으로 쌓인 `MaterialLayer { material, thickness, role(base·body·face), face?, side? }`. 마감(도색·시트)은 어느 층의 앞면·옆면에도 붙는다. 종류(고무 스카시 등)는 기본 묶음(`defaultStack`)일 뿐 — 층을 빼고 더한다.
- **구성 요소 레지스트리**(`core/components`)와 **레이어 트리**(`core/layers.ts`): 프레임 → 구성 요소 → 글자·그림, 부모 기준 좌표. 3D 는 트리를 돌며 깊이를 쌓는다.
- **세트 라이브러리**(`core/setLibrary.ts`): 레이어 일부를 저장해 비율 유지로 넣기. 레시피는 이것을 사인물 전체로 넓힌 것.

## 2.5D 단면 쌓기 화면
**왜 2.5D 인가**: 정면도는 층이 겹쳐 안 보이고, 3D 는 휴대폰에서 무겁고 돌려야 해서 고치기 어렵다. 비스듬히 내려다본 고정 시점은 **모든 층이 한눈에** 보이고, 글자가 또렷하며, 그림이 그대로 PDF·주문서에 들어간다.

- **투영**: 경사 투영(cabinet) — 가로는 그대로, 세로는 그대로, 깊이(두께)는 오른쪽 위 30°로 비스듬히. 두께는 실제보다 **과장**(최소 표시 두께를 두어 1.2T 판도 보이게, 실제 값은 이름표에). SVG 로 그린다(Three.js 아님 — 가볍고, 휴대폰에서 바로, 인쇄 가능). 실사·회전은 기존 3D 창이 맡는다.
- **모양**: 각 층은 그 구성 요소의 윤곽(글자면 글자 윤곽, 판이면 사각·둥근 사각)을 두께만큼 밀어낸 판. 글자는 대표 글자 한두 자로 줄여 그려도 된다(전체 문구는 정면도에).
- **펼치기**: [붙임 ↔ 펼침] — 펼침이면 층 사이를 띄워(분해도) 사이에 낀 LED·시트도 보이게.
- **이름표**: 층마다 지시선 + "고무 20T · 앞면 도색 RAL 3020". 마감은 층의 앞면·옆면 색으로 칠한다(시트는 무늬).
- **속성은 단면 아래 접이**(2026-10-22 사용자: "단면 하단에 폴딩으로 속성은"): 2.5D 그림 아래에 **층마다 접힌 줄** — 접힌 줄에는 "③ 고무 20T · 앞면 도색" 처럼 요약만, 펼치면 그 층 속성(재질·두께·앞면 마감·옆면 마감·가공). 한 번에 한 층만 펼친다(아코디언). 그림에서 층을 누르면 그 층 줄이 펼쳐지고, 줄을 펼치면 그림에서 그 층이 강조된다(서로 같은 선택). 줄 순서 = 그림의 쌓인 순서(앞이 위).
- **고치기**(S2): 펼친 줄에서 속성을 고치고, 줄을 위아래로 끌어 순서, 줄 사이 [+] 로 재료 카드 넣기, ✕ 로 빼기. 고치면 2.5D·3D·견적·주문서가 같이 바뀐다(같은 `stack`). 고칠 수 없는 화면(보기 권한)에서는 펼친 속성이 글자로만(권한별 화면 규칙).
- **휴대폰**: 같은 배치 — 위 2.5D 그림, 아래 접이 속성. 그림이 작아도 접이 줄로 다 고칠 수 있다.
- **자리**: 사인물 설정 창의 구성 요소 탭 위쪽(지금 재료 층 목록 자리), 그리고 레시피 미리보기·썸네일.

## 재료 카드 (S3)
재료 하나 = `{ 재질, 두께 규격(고를 수 있는 값), 마감 가능(도색·시트·헤어라인·미러), 가공(레이저·CNC·절곡·밴딩), 실내외, 단가 연결(면적·길이·개수), 공급사 }`. 지금의 `STACK_MATERIALS`(철판·고무·알루미늄·스텐·티타늄·아크릴·포맥스)를 카드로 넓히고, 계정·팀이 재료를 더한다(색 라이브러리처럼). 확인 필요: 자주 쓰는 재질·두께 규격·가공 목록 — 사용자 예시로 채운다.

## 레시피 라이브러리 (S4)
- 저장: 사인물 전체(프레임 + 구성 요소 + 재료 층 + 글자·그림) + **변수**(가로·세로·글자 수·두께) + 썸네일(2.5D 그림).
- 가져오기: 크기를 넣으면 재료 길이·면적·견적을 다시 계산(지금의 비율 유지 `fitScale` 을 변수 기반으로). **자리표시 글자**(`{상호}`)는 가져올 때 바꾼다.
- **변형**: 같은 레시피의 조명 유무·색만 다른 버전 — 제안 페이지에서 고객이 고를 수 있게.
- **잠금 칸**: 작성자가 바꿔도 되는 칸만 연다(직원·고객이 구조를 깨지 않게).
- 범위: 내 것 · 팀 · 간판다 기본. 태그(재료·조명·실내외·가격대). 실적(견적·수주 건수, 평균 금액)을 붙여 영업 자료로.

## 조합 규칙 · 자재 명세 (S5)
- 재료끼리 붙는 방식(접착·볼트·용접·매립)과 피할 조합을 표로 — 쌓을 때 경고와 대안.
- 재료 층에서 **자재 명세**(재질별 면적·길이·개수) → 주문서를 **공급사별 발주**로 나눈다.

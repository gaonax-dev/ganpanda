# 커뮤니케이션 (대화·코멘트)

## 요약
사인물 오브젝트마다 카톡형 대화와 검토 코멘트를 주고받습니다. 1차 개발의 중심 기능입니다.

## 상태
일부 구현 — 오브젝트별 대화·코멘트는 구현, **다른 사람과의 실시간 공유는 1차 예정**(앱 ↔ 서버 연결 필요)

## 동작
- 오브젝트 패널 아래쪽에 [대화] / [코멘트] 탭이 있습니다. 둘 다 `messages` 배열에 `kind`로 구분해 저장합니다.
- 대화: 내 메시지는 오른쪽 노란 말풍선, 다른 사람은 왼쪽 흰 말풍선 + 이름. 같은 사람이 연속으로 보내면 이름은 한 번만 표시합니다.
- 코멘트: 왼쪽 강조선이 있는 메모 카드입니다.
- Enter로 전송, Shift+Enter로 줄바꿈. 한글 조합 중 Enter는 전송하지 않습니다(`isComposing`).
- 표시 이름은 처음 보낼 때 묻고 `localStorage`의 `ganpanda.nickname`에 저장합니다. 상단 오른쪽에서 바꿀 수 있습니다.

## 알려진 한계
- "내 메시지" 판단이 이름 비교입니다. 같은 이름을 쓰는 다른 사람도 내 메시지로 보입니다. → 로그인·참여자 ID 도입 시 교체
- 안 읽은 메시지 표시, 알림 없음

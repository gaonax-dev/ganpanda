# 공급 단가표 (거래업체 단가) + 내 단가표

## 요약
사용자 요청(2026-10-16): "한울 단가표이다. 해당 단가는 한울 꼬리표가 있어야 한다. 추후 거래업체에 단가표를 공급받아 제공하려한다. 현재는 사용자가 등록한 단가표로 구성해 해당 사용자만의 단가표이다. 지금은 개발중으로 둘다 구성하고 추후 업로드나 api로 단가를 공급받고 사용자가 입력가능하게".

- **공급 단가표**: 거래업체(지금은 한울상사)가 주는 원가표. 읽기 전용 참고값이며 품목마다 공급업체 **꼬리표**(예: `한울`)가 붙습니다.
- **내 단가표**: 사용자(제작자)가 정하는 판매 단가(`PriceTable`, [sign-list-quote.md](sign-list-quote.md)). 견적은 언제나 내 단가표로 냅니다.
- 둘을 잇는 것이 **연결(link)**: 내 단가 항목을 공급 품목에 연결하면 그 단가를 가져오고, 견적 줄에 `· 한울 단가` 꼬리표가 붙습니다. 직접 고치면 연결이 풀립니다(꼬리표 = 공급업체 단가 그대로라는 뜻).

## 데이터 (`src/lib/core/supplierPrices.ts`)
```ts
SupplierPriceList { supplier: { id, name, tag }, effectiveDate: 'YYYY-MM-DD', source: 'pdf' | 'upload' | 'api', items: SupplierItem[] }
SupplierItem { id /* '<공급업체>.<분류키>.<이름>[.<세부>]' */, group, name, option?, maxWidthMm?, unit: '회배' | '장' | '개' | 'm', price, surcharge?, note? }
PriceTable.links?: Record<단가 항목 id, '<공급업체 id>:<품목 id>'>
```
- **회배 = 1m × 1m = 1㎡** — ㎡ 단가 항목에는 회배 기본 품목만, m 은 m, 개 는 개 품목만 연결할 수 있습니다(`linkableItems`, 추가금 제외).
- `mergePrices` 는 알 수 없는 항목 id·없는 품목을 가리키는 연결을 버립니다. 서버(`/api/me/prices`)는 `links` 를 문자열 맵(100개, 200자 이하)으로만 검사합니다.
- `parseSupplierList(raw)`: 공급업체(id 소문자·숫자·-, 이름, 꼬리표)·적용일이 없으면 거부. 품목은 id 중복·이름 없음·모르는 단위·음수 단가를 이유와 함께 빼고 나머지를 받습니다.

## 공급사 계산법 (`core/calcMethods.ts`, 2026-10-16)
사용자: "공급사별 계산법을 사용할 수 있게해줘". 공급 단가표의 세부 표기를 읽어 계산법을 **자동으로** 만듭니다 — 공급업체마다 표 모양이 달라도 표기만 맞으면 같은 엔진(새 단가표를 업로드해도 그대로).

| 종류 | 만드는 조건 | 계산 | 예 |
|---|---|---|---|
| `letters` 글자 크기 구간 자당 | 같은 품목의 자당 단가가 모두 크기 구간(`30cm`, `30각`=cm, `10mm`, `10cm 이하`, `11~20cm`)을 가짐. 나머지 세부(예 `LED조립`, `고무 5T~30T`)마다 따로 | 글자 객체마다 높이 이상인 가장 작은 구간 × 글자수. 글자에 한글이 있으면 한글 단가. 가장 큰 구간보다 크면 그 구간 + "(최대 구간 초과)" | 알리다 캡 채널·갈바 채널·오사이·일체형·3D 채널·고무 스카시·레이저 (44개) |
| `width` 폭 구간 ㎡ | ㎡ 품목 2개 이상, 세부가 폭(단폭·장폭·소폭)을 말하고 최대폭이 서로 다름 | 짧은 변이 들어가는 가장 좁은 폭의 단가 × 면적 | 한울 플렉스·솔벤 현수막·텐트천, 알리다 후렉스 출력 |
| `area` 헤베 + 기본가 + 광폭 | "N헤베(M) 기준" 단가 + "기본가격(1.8헤베)" 고정가 (+ "광폭(2,010폭 이상)") | 1.8헤베(돌출은 긴 변 1.8M)까지 기본가, 넘으면 면적(길이) × 단가. 짧은 변이 광폭 이상이면 광폭 단가 | 알리다 비조명·조명·돌출 프레임 간판 |
| `areaTier` 면적 구간 | 세부가 모두 "N회배 이하/미만/이상" | 맞는 구간이 장당이면 그 금액, 회배당이면 × 면적 | 한울 현수막 |

- 저장: `PriceTable.methods: { 단가 항목 id: 계산법 id }` — 연결(links)보다 우선. 금액 = 계산법 금액 × 배수(쓰인 품목의 분류 배수). 직접 출력 분류의 계산법은 고를 수 없고, 분류를 직접 출력으로 바꾸면 풀립니다.
- 적용: 간판 몸통 ㎡(`area`·`width`·`areaTier`), 채널·스카시 구성 요소(`letters`), 시트 구성 요소·옛 시트(면적 계산법, 크기 있는 객체마다).
- 견적 설명은 **배수를 곱한 단가**로 보입니다(공급가·배수를 고객에게 드러내지 않음). 줄에 `· 알리다 단가` 꼬리표.
- 화면: 단가 항목의 선택 상자에서 "직접 입력 / <공급업체> 계산법 / 공급 품목" 중 고름. 계산법이면 단가 칸은 "계산법"으로 잠김.

## 배수 (`core/markup.ts`, 2026-10-16)
사용자: "이건 소비자가 예시로 한울 가격을 몇배로 할지 조정해봐" → "단가는 사용가 설정할거고 나는 그냥 샘플이 필요할 뿐이야".
- `PriceTable.markup = { all, groups? }` — 배수는 사용자가 단가 설정 창에서 정합니다(전체 `markup-all`, 분류별 `markup-<분류>`, 비우면 전체 배수). 0 초과 10 이하.
- **직접 출력**(`markup.direct`, 2026-10-16 사용자: "직접출력은 시트 후렉스 uv실사출력이고 나머지는 기존배수를 적용해야한다"): 직접 출력하는 분류는 공급 단가에 연결하지 않고 직접 입력합니다. 연결 목록에서 빠지고, 분류를 직접 출력으로 바꾸면 이미 연결된 항목은 풀리고 단가는 남습니다(`isDirect`, `applyMarkup`). 그 밖의 분류는 배수를 적용합니다. **샘플 기본값**(`DEFAULT_PRICES.markup`): 전체 ×1, 직접 출력 = 한울 UV(실사 시트)·플렉스(후렉스)·UV시트평판 + 알리다 후렉스·시트·UV 평판 출력 분류. 단가 설정 창에서 공급업체를 펼쳐 분류마다 `direct-<분류>` 체크·`markup-<분류>` 배수.
- 연결 단가 = 공급 단가 × 배수를 100원 단위로 반올림(`linkedPrice`). 배수를 바꾸면 연결 항목만 다시 계산(`applyMarkup`), 직접 입력 항목은 그대로.
- 샘플 참고(코드에 넣지 않음): 가오낙스 `단가표.xlsx`(처음엔 소비자가 예시로 받았으나 숫자가 알리다 공급 단가와 같음 — 사실상 **알리다 ÷ 한울** 비교)의 같은 품목 22개를 한울 단가와 비교하면 중앙값이 시트 출력(UV·반사) ≈ ×1.0, 후렉스 출력·수성 배너 ≈ ×0.8, 후렉스 마감(클램프·고주파) ×1.0, 전체 ≈ ×1.0. 프레임 간판(헤베당 틀 등급)·광확산 PC 채널(크기별 개당)은 한울 단가표에 없어 비교하지 않았습니다.

## 화면 (`ui/PricesDialog.svelte`)
- 항목 줄: 이름(연결되면 꼬리표 `price-tag-<id>`) · 단가(`price-<id>`) · 단위 · 공급 단가(`price-link-<id>`: 직접 입력 / 공급업체·분류별 품목).
- 아래 **공급 단가표**(`supplier-lists`): 전체 배수, 공급업체마다 꼬리표·이름·적용일·품목 수. 누르면(`supplier-toggle-<id>`) 품목 찾기(띄어쓴 낱말이 모두 들어간 품목만)와 분류별 표(분류 머리에 직접 출력·배수, 이름·세부·최대폭·단가/단위(자당은 `원/자`), 추가금은 `+`).
- 개 단위 제품(1식)의 연결 목록에서는 자당(글자) 단가를 뺍니다.

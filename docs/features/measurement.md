# 실측 판독과 카메라 설정

## 요약
사진의 원근을 **사진별 카메라 설정**으로 잡고, 그 벽면 위에서 사인물의 실제 크기를 추정하며 입력 치수가 어긋나면 경고합니다. AI(학습 모델)는 쓰지 않고, 사진의 직선을 찾아 축 선을 제안하는 것과 끝점을 모서리에 붙이는 것만 자동입니다.
1. **카메라 설정**(2026-10-14, 사용자 결정 — 사인물과 분리): 가로·세로 축 선 두 쌍 + 원점 + 기준 길이 → 초점거리·회전·위치 → 벽면 평면. 설정이 있으면 이 방식.
2. **자동 기준**(대체용): 카메라 설정이 없으면 가로·세로를 모두 입력한 첫 사인물을 기준으로 같은 평면 가정.

## 상태
구현됨 — `src/lib/core/camera.ts`(솔버·자동 제안), `src/lib/core/calibration.ts`(측정·모서리 붙이기), `src/lib/core/measure.ts`(판독), `src/lib/ui/CameraDialog.svelte`, `src/lib/ui/CameraPanel.svelte`

## 왜 사인물과 분리했나
처음(2026-10-13)에는 실측한 사인물의 변을 가로·세로 기준선으로 썼습니다. 그러나 사인물은 그리기 편한 대로 그리는 것이라 벽의 축과 어긋날 수 있고, 치수·기준·영역 편집이 한 객체에 뒤섞여 복합 문제가 됐습니다(사용자: "사인물로 기준선을 잡는 건 복합적인 문제가 있다"). fSpy 와 같은 방식 — 축 선 두 쌍, 원점(피봇), 기준 길이 — 으로 **카메라를 사진의 속성**으로 두고, 사인물은 영역·종류·치수만 갖게 했습니다. `refH/refV`, `Photo.calib`, 기준선 패널·조정 창은 제거됐습니다.

## 라이선스
fSpy 는 GPL v3 입니다. 간판다는 fSpy 코드를 한 줄도 쓰지 않고 교과서 기하(Caprile & Torre 1990, Hartley & Zisserman)를 수식에서 직접 구현했습니다(`camera.ts` 머리말). UI 개념(축 선 쌍·원점·기준 길이)은 아이디어라 저작권 대상이 아니며, 기능 이름에 "fSpy"를 쓰지 않습니다.

## 카메라 설정 (`camera.ts`)
### 입력 (`Photo.camera: CameraSetup`, 문서에 저장 → 실시간 공유·⌘Z)
| 항목 | 내용 |
|---|---|
| `x: [Line, Line]` | 벽의 가로 방향 직선 2개 (줄눈·간판 띠·창틀 위아래) |
| `y: [Line, Line]` | 세로 방향 직선 2개 (문틀·창틀 좌우) |
| `z?: [Line, Line]` | 깊이 방향(옆면 벽) 2개 — 있으면 제3 소실점 |
| `origin` | 벽 좌표 (0,0) 이 되는 사진 점 (보통 벽 왼쪽 아래 모서리) |
| `ref?: {a, b, axis, mm}` | 축을 따라 놓인 실측 선 하나 (문 폭 900 등) → 축척 |
| `principal?` | `center`(기본) / `third`(세 소실점의 수심 — 잘라낸 사진용, z 필요) |

### 풀이 (`solveCamera(setup, imgW, imgH)` → `CameraSolution`)
1. **소실점**: 각 쌍의 두 선 교점(동차 좌표). 두 선이 거의 평행(방향 내적 > 0.9999)이면 경고.
2. **주점**: 사진 중앙, 또는 `third` 이면 세 소실점 삼각형의 **수심**(`orthocenter`). 소실점이 무한원점이면 중앙으로 되돌리고 안내.
3. **초점거리**: 두 소실점 직교 (vx−pp)·(vy−pp) = −f². f 가 장변의 0.25~5배를 벗어나거나 소실점이 무한원점(정면 사진)이면 기본값 장변×0.75 를 쓰고 안내 — 정면이면 평면 위 치수에는 영향이 없습니다.
4. **회전**: r₁ ∥ K⁻¹vx(사진 오른쪽이 +), r₂ ∥ K⁻¹vy(사진 위가 +), 그람-슈미트 직교화, r₃ = r₁×r₂ (벽 밖, 카메라 쪽).
5. **위치**: 원점은 광선 K⁻¹o 위. 깊이 s 는 기준 길이로 — s=1 로 벽면 호모그래피를 만들어 기준 선 양끝을 벽 좌표로 보내고, 축 방향 길이 L₁ 에 대해 s = mm / L₁. 기준 길이가 없으면 s=1000(단위 미정) + 경고.
6. **벽면 호모그래피** H = K[r₁ r₂ t] (벽 mm → 사진 px) 와 역행렬. `calibrationOf(sol)` 이 기존 실측·벽면 코드가 쓰는 `Calibration {H: Hinv, sx: sy: 1}` 로 바꿔 줍니다.
- 검증(단위 테스트, 합성 핀홀 카메라): 벽 위 점 재투영 1px 안, 초점거리 1% 안, 창 1500×850 이 1% 안, 세로 기준 길이, **잘라낸 사진**은 z 축 + `third` 로 주점 복원(중앙 가정은 5px 이상 어긋남), 정면 사진, 평행·기준 없음 경고.
- `CameraPose` 에 `pp`(주점)가 생겨 `projectPoint` 와 실사 뷰어(`setViewOffset`)가 중앙이 아닌 주점을 지원합니다.

### AI 자동 제안 (`proposeAxisLines(gray)`) 과 모서리 붙이기 (`snapSetup`)
- 그라디언트가 큰 픽셀(평균의 3배 이상)을 1° 간격 **허프 변환**으로 모아 강한 직선 후보를 찾고, 법선이 세로에 가까운 것(±35°) 중 **위·아래로 멀리 떨어진 두 선**(30% 이상, 없으면 절반씩 낮춤)을 가로 선으로, 법선이 가로에 가까운 것 중 좌·우로 떨어진 두 선을 세로 선으로 고릅니다. 끝점은 그 선을 받치는 에지 픽셀의 5~95% 범위. 큰 사진은 건너뛰며 봅니다(장변/600). 뚜렷한 직선이 모자라면 null → "직접 놓으세요".
- `snapSetup`: 모든 축 선 끝점을 `snapEdge`(법선 ±8px 에서 밝기 변화 최대 위치, 신뢰도 0.2 미만이면 그대로)로 사진 모서리에 붙입니다. 원점·기준 길이는 손대지 않습니다.
- 합성 사진(벽·띠·창)에서 제안 선이 실제 축과 5° 안, 그 선으로 푼 초점거리가 10% 안(단위 테스트).

## 화면
- **사진마다** 이름 바에 **[📐 원근 맞추기]**(없음) / **[📐 원근 맞춤 ✓]**(설정됨, `camera-open`, `data-status`). 설정된 사진에는 축 선·원점·기준 길이가 옅게 겹쳐 보여(`camera-overlay`) 어느 사진에 설정이 있는지 바로 알 수 있습니다. (2026-10-14 사용자 피드백: 떠 있는 패널은 어느 사진 것인지, 무엇을 하라는 것인지 이해하기 어려웠음 → 사진 위로 이동, "카메라 설정" 대신 "사진 원근 맞추기")
- **원근 맞추기 창**(`CameraDialog.svelte`, `app.cameraPhotoId`/`cameraDraft`): 머리말에 "이 사진에서 치수를 재고 실사를 합성하려면…" 한 줄 설명. [설정 지우기](`camera-clear`)는 창 안에. 사진 위에 가로 선(노랑)·세로 선(파랑)·깊이 선(초록, 체크로 추가)·원점(흰 십자)·기준 길이(빨강 + mm 입력 + 가로/세로 방향). 모든 끝점(`camera-handle`, `data-key` = `x0a`…, `o`, `ra`/`rb`)을 끌 수 있고 3배 돋보기가 뜹니다. [축 선 자동 제안](`camera-propose`) → AI 가 선을 놓고 끝점을 붙임, [모서리에 붙이기](`camera-snap`). "결과"에 초점거리·주점·경고가 실시간. [적용]은 `Photo.camera` 저장(⌘Z), Esc·취소는 버림. 처음 열면 사진 크기 기준 기본 배치(`defaultCameraSetup`)로 시작합니다.
- 사인물 설정 창에서 치수 입력칸의 placeholder 가 카메라 기준 추정값(≈)입니다. 어긋나면 "카메라 설정 기준 약 W × H 로 보입니다" 경고와 [추정값 적용].

## 측정 (`measure.ts`)
- 카메라가 있으면 모든 영역을 `measureQuad`(사각 영역을 벽 mm 로 보내 위·아래 변 평균 = 가로, 좌·우 변 평균 = 세로)로 추정하고, 입력 치수가 12%(`TOLERANCE`) 넘게 다르면 `scale` 경고.
- 없으면 **자동 기준**: 가로·세로가 모두 입력되고 모양이 정상(`isValidQuad`)인 첫 사인물을 기준("기준 영역" 배지)으로 `sizeOnPlane`. 기준이 없으면 단독 비율 검사(`aspect`).
- 한 사진의 영역이 모두 같은 벽면이라고 가정합니다. 옆면 벽은 "존 = 벽면"(로드맵 7-3)에서 다룹니다.

## 공통
- [추정값 적용]은 10mm 단위 반올림. 치수를 입력하지 않은 사인물은 추정 치수로 견적에 반영하고 "추정" 표시(`app.sizeOf`).
- 실사 보기와 벽면 좌표계(`wallPlane.ts`)도 같은 보정을 씁니다 → [render-3d.md](render-3d.md).

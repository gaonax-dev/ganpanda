# 실측 판독

## 요약
사용자가 입력한 치수가 사진과 맞는지 원근 기하로 검사하고, 맞지 않으면 경고합니다. AI를 쓰지 않습니다.

## 상태
구현됨 — `src/lib/core/measure.ts`

## 규칙
1. **기준 영역**: 한 사진 안에서 가로·세로가 모두 입력되고 모양이 정상(`isValidQuad`)인 **첫 번째 오브젝트**(생성 순)입니다. 패널에 "기준 영역" 배지가 붙습니다.
2. **추정**: 다른 오브젝트는 기준 영역의 원근(호모그래피)으로 실제 크기를 계산합니다 (`sizeOnPlane`). 치수칸의 회색 안내 문구(`≈ 2,000`)로 보여 줍니다.
3. **기준 대비 경고 (`scale`)**: 입력한 가로 또는 세로가 추정값과 **12% 넘게**(`TOLERANCE = 0.12`) 다르면 경고합니다.
4. **비율 경고 (`aspect`)**: 기준 영역이 없을 때(또는 자신이 기준일 때)만 검사합니다. 입력한 가로와 기본 초점거리로 사진상 세로를 계산해 12% 넘게 다르면 경고합니다.
5. **경고는 하나만**: 기준 영역이 있으면 비율 경고는 내지 않습니다(기준 대비가 더 정확함).
6. **추정값 적용** 버튼은 기대값을 10mm 단위로 반올림해 입력합니다.
7. 치수를 입력하지 않은 오브젝트는 **추정 치수로 견적**에 반영하고 "추정"이라고 표시합니다 (`app.sizeOf`: 입력값 우선, 없으면 추정값).

## 가정과 한계
- 한 사진 속 영역은 모두 **같은 벽면(평면)**에 있다고 가정합니다. 꺾인 벽·돌출 간판처럼 다른 면에 있으면 오경고가 날 수 있습니다.
- 비율 경고는 초점거리 기본값(장변 × 0.75)에 의존합니다. 정면에 가까운 사진에서는 초점거리 영향이 작습니다.
- 찌그러진 영역은 기준이 될 수 없고, 추정 대상에서도 빠집니다.

# 실측 판독

## 요약
사용자가 입력한 치수가 사진과 맞는지 원근 기하로 검사하고, 다른 영역의 실제 크기를 추정합니다. AI(학습 모델)는 쓰지 않습니다. 두 방식이 있습니다.
1. **기준선 보정**(2026-10-13, 사용자 결정): 실측한 사인물의 변을 **가로 기준·세로 기준으로 따로 지정** → AI 평가(모서리 보정·모순 점검) → 전체 적용. 사진에 적용된 보정이 있으면 이 방식.
2. **자동 기준**(이전 방식, 대체용): 가로·세로를 모두 입력한 첫 사인물을 기준으로 같은 평면 가정.

## 상태
구현됨 — `src/lib/core/calibration.ts`(기준선), `src/lib/core/measure.ts`(판독)

## 기준선 보정 (`calibration.ts`)
- **기준선 지정**: 치수를 입력한 사인물 패널의 [가로 기준](위·아래 변 = 가로 mm) / [세로 기준](좌·우 변 = 세로 mm) 체크. 확실한 것만, 여러 사인물에 걸쳐 여러 개 가능. 따로 선을 긋지 않습니다.
- **원근**: 가로 기준선들의 소실점·세로 기준선들의 소실점(3×3 최소 고유벡터)으로 벽면을 정면 보정하는 호모그래피를 만들고(소실점 → 무한원점), 보정 좌표에서 가로 기준선 길이로 **가로 축척**, 세로 기준선 길이로 **세로 축척**을 따로 정합니다(여러 개면 평균). 정면 사진(선 평행)도 동차 좌표로 자연히 처리됩니다.
- 한 축의 기준이 없으면 그 축의 소실점을 사진 축으로 가정하고 다른 축척을 씁니다(근사, 안내 문구).
- **모순 점검**: 기준선마다 암시하는 축척이 평균과 10%(`REF_TOLERANCE`) 넘게 다르면 경고(어느 사인물의 어느 변인지).
- **AI 평가**(`snapEdge`): 각 기준선을 법선 방향 ±8px 로 옮겨 보며 밝기 변화가 가장 큰 위치(사진 속 실제 모서리)에 붙입니다. 신뢰도 = (최대 변화 − 평균)/최대, 0.2 미만이면 "모서리 못 찾음"으로 움직이지 않음. 변의 이동은 꼭짓점에 합산됩니다(한 꼭짓점 = 두 변).
- **전체 적용**: 보정된 사각 영역을 사인물에 저장(⌘Z 가능)하고 `Photo.calib = { key }`에 기준선 구성 키(사인물·변·mm·좌표)를 기록. 구성이 바뀌면(기준 해제·치수 수정·영역 이동) `stale` → 다시 평가·적용해야 합니다.
- 측정(`measureQuad`): 사각 영역을 보정 좌표로 보내 위·아래 변 평균 × 가로 축척, 좌·우 변 평균 × 세로 축척.

## 자동 기준 (대체 방식)
1. 사진 안에서 가로·세로가 모두 입력되고 모양이 정상(`isValidQuad`)인 **첫 번째 사인물**이 기준. "기준 영역" 배지.
2. 다른 사인물은 기준 영역의 호모그래피로 크기를 추정(`sizeOnPlane`). 12%(`TOLERANCE`) 넘게 어긋나면 경고(`scale`).
3. 기준이 없을 때만 단독 비율 검사(`aspect`, 기본 초점거리 가정).
4. 한 사진의 영역이 모두 같은 평면이라고 가정합니다.

## 공통
- [추정값 적용] 버튼은 기대값을 10mm 단위로 반올림해 입력합니다.
- 치수를 입력하지 않은 사인물은 추정 치수로 견적에 반영하고 "추정"으로 표시합니다(`app.sizeOf`).
- 기준선 사인물은 기준 축에 대해서는 경고하지 않습니다(정의상 일치).

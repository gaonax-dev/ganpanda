# 채널 라이브러리 — 사진으로 빠른 선택 (2026-10-23)

사용자(2026-10-23): 15가지 채널간판 시안 사진(3D 채널 문자 "G")을 주며 "사인물 라이브러리 생성하고 사진 이미지로 선택하면 적용하게" → "간판 선택하고 채널 나오면 사용자들이 퀵으로 선택하고 여기에서 디테일을 추가하거나 빼는 방향으로 가려한다."

## 동작 — 구현됨
- 간판에 **[+ 채널]**을 넣으면 채널 카드 위에 **15종 사진**(`preset-pick`, `public/channel-types/01~15.webp`)이 펼쳐진다(옵션이 아직 없는 새 채널). 사진을 누르면 그 **채널 종류 + 옵션 묶음**이 들어가고 접힌다.
- 접힌 상태(`preset-current`): 고른 사진·이름·설명, **[사진으로 고르기]**(`preset-open`)로 다시 펼친다. 세부를 하나라도 바꾸면 **"직접 고침"**(묶음 판정 `presetOf` — 종류·옵션이 묶음과 같을 때만 그 묶음).
- 그다음은 지금의 채널 편집기(옵션·재료 층·글자)에서 세부를 더하거나 뺀다. 고를 때 글자·올린 곳·id 는 그대로, 재료 층을 저장해 둔 채널은 새 종류의 기본 묶음으로(`applyPreset`).
- 옵션으로 아직 표현하지 못하는 사양은 `preset-gap` 으로(L3 이후 해당 없음) "아직 옵션에 없음: … — 요청사항에 적어 주세요".
- 구조: 묶음 데이터 `core/channelLibrary.ts`(`CHANNEL_PRESETS`) → 채널 레지스트리 `presets` → 적용·판정 `core/partPresets.ts`(종류 무관). 다른 구성 요소(스카시·시트)도 `presets` 만 채우면 같은 UI.
- 보기 권한(ro)에는 고르기가 없다.

## 채널 옵션 보강 (L2) — 구현됨 2026-10-23
| 옵션 (키) | 보이는 때 | 값 | 반영 |
|---|---|---|---|
| 몸통 마감 `chFinish` | 채널(갈바 제외) | 도장 · 헤어라인 · 미러 · 티타늄 골드/로즈골드/블랙 | 도장이 아니면 **몸통 도색 칸 없음**. 3D 옆면 금속: 헤어라인(결 있는 금속), 미러·티타늄(거울, 티타늄은 코팅 색) |
| 띄움 거리 `chStandoff` (mm) | 까치발을 켰을 때 | 비우면 30 | 3D 글자를 벽(앞면)에서 띄우고, 후광 번짐이 띄움에 비례(35mm 기준 0.6~2배) |
| 뒤판 `chBack` | 후광 · 전후광 | 투명 아크릴 · 유백 아크릴 · **앞면과 같게** | 벽에 번지는 빛 색 = LED 색, 앞면과 같게면 앞면 색 |
| 단차 높이 `chStep` (mm) | 캡 단차(아크릴) | | 기본 재료 층의 앞판(아크릴) 두께, 몸통이 그만큼 줄어 합은 깊이 그대로 |
| 앞면 마감 `chGalvaFace` | 갈바 에폭시 채널 | 에폭시 · 도장 | 01 갈바 전면 / 10 에폭시 구분 |
| 전구 간격 `chBulbPitch` | 벌브 | 50 · 70 · 100mm | 요약·주문서 (3D 전구는 L3) |

- **전후광 = 앞 + 뒤 발광**: 3D 에서 앞면 발광에 더해 벽 후광(밤에 진하게) — `look3d.backLit`.
- 옛 **`양면 (돌출용 전후광)`(chDouble) 칸은 없앴다** — 견적·3D 에 쓰이지 않았고 "양면 = 전후광"과 뜻이 겹친다. 저장된 값은 남아도 쓰지 않는다.
- 3D 는 레지스트리 `look3d(part)`(마감·옆면 색·띄움·뒤 빛·후광 색)를 `core/render.ts` 가 글자 객체에 얹고 `sim/signs.ts buildChannel` 이 그린다.
- 단가: 새 옵션은 아직 금액에 반영하지 않는다(단가표 항목 없음 — 상담).

## 채널 빛 (L3) — 구현됨 2026-10-23
- **점등 / 비조명** `chLight`(전광·후광·전후광): 비조명이면 조명 없음 — LED 색·뒤판 칸, 재료 층의 LED, 3D 발광·후광이 모두 빠진다. 13 오사이 용접 = 비조명 미러 스텐.
- **일체형 = 앞면과 옆면이 함께 빛남**(`look3d.sideLit`): 3D 옆면도 앞면 색으로 발광(밤에 진하게). 11 일체형.
- **벌브 전구 3D**(`look3d.bulbPitchMm`, 전구 간격 기본 70mm): 앞면은 도장(발광 안 함), 전구가 **획 가운데부터 간격대로**(`sim/bulbs.ts spacedPoints` — 고운 격자 후보를 가장자리에서 먼 순으로, 서로 간격 이상) 늘어서고 밤에 켜진다. 번짐 = 전구(LED) 색.
- **까치발 받침 3D**: 띄움 거리가 있으면 글자마다 2~3개 금속 봉(벽 → 글자 뒤, `insidePoints`).
- 15종 묶음의 "아직 옵션에 없음"은 이제 없다.

# 조합형 사인물 (간판 프레임 + 구성 요소 + 내용 객체)

## 요약
사용자 요청(2026-10-16): "조합형으로 구성할 수 있을까 사인물 간판프레임+체널,스카시,시트 / 간판프레임 아래에 선택가능한 리스트를 넣어주면 해당 객체를 사용한다 / 채널 객체에 포함된 글자 입력객체를 간판 중앙에 배치하고 크기와 위치지정 가능하게 / 다시 스카시 객체를 선택하면 스카시 옵션이 나오고 글자 입력객체 사용 그림입력객체도 있음 / 체널도 추가 할수 있는 시트를 올려 커팅시트, uv출력 시트. 당연히 시트도 글자 그림 객체 글자와 객체 여러개 / 자주사용하는 것은 셋을 모아서 저장하면 라이브러리(이미지아이콘)를 가져다 사용".
답: 그림 객체는 어느 구성 요소에나("뭐든 붙일 수 있다"), 그림 소스는 디자인 파일과 직접 올린 그림 둘 다, 라이브러리는 팀 공유, 다른 크기에는 비율 유지, 1~2단계 먼저.

사인물 = **간판 프레임**(종류·옵션·치수·상단 조명) + **구성 요소**(채널·스카시·시트, 여러 개) + **내용 객체**(구성 요소마다 글자·그림, 여러 개).

## 상태
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 데이터 구조(`SignObject.parts`), 옛 데이터 변환(읽을 때), 구성 요소별 견적·요약·주문 JSON·3D 연결 | 구현됨 (2026-10-16) |
| 2 | 설정 창의 구성 요소 UI (추가·삭제·세부 종류·옵션·글자/그림 객체·위치/크기 mm·시트 올릴 곳) | 구현됨 (2026-10-16) |
| 2b | **모든 분류 조합형** + 중복 정리 (아래) | 구현됨 (2026-10-16) |
| 3 | 정면도 편집기 (끌어 배치·크기·정렬·스냅) | 계획 |
| 4 | 3D·평면도·PDF·사진 합성에 객체 위치 반영 (지금 3D 는 첫 채널(없으면 스카시)의 글자를 이어 붙이고 가장 큰 높이) | 계획 |
| 5 | 라이브러리: 세트 저장(썸네일 아이콘), 팀 공유, 가져다 쓰면 비율 유지로 맞춤 | 계획 |

## 모든 분류 조합형 · 중복 정리 (2026-10-16)
사용자: "사인물 상세설정들을 모두 조합형으로 변경해주고 중복도 확인해줘 포맥스의 경우 실측에 두께가 있어 포멕스 두께가 따로표시 중복된다."

**분류마다 붙일 수 있는 구성 요소** (`partKindsFor`, 설정 창의 [+ …] 단추도 이것만):

| 분류·종류 | 구성 요소 |
|---|---|
| 간판 (채널이 붙는 몸통, 옛 채널 제품) | 채널 · 스카시 · 시트 |
| 스카시 | 스카시 (사인물 자체가 스카시 — 카드 하나로 시작) |
| 시트 (제품 없음) | 시트 (시트 칩·문구 칸 대신 시트 카드. 시트 카드가 있으면 시트 분류 유지) |
| 포맥스 · 아크릴 액자·현판 | 시트 · 스카시 |
| 라이트패널 · 패브릭 라이트박스 · 프레임 액자 · 어닝 · 사인미러 | 시트 |
| 현수막 · 나무틀 패브릭 액자 · 천갈이 · 전광판 · 에어간판 | 없음 (그 자체가 출력물·완제품) |

분류·종류를 바꾸면 새 종류에 못 붙는 구성 요소는 빠지고, 빠진 채널 위의 시트는 프레임 면으로(`partsForProduct`, `categoryPatch`).

**겹치던 설정 정리**

| 겹침 | 정리 | 옛 값 |
|---|---|---|
| 포맥스·아크릴 `두께` 선택 ↔ 치수 **두께** | 선택 없앰. 치수 두께 아래 빠른 선택 3·5·8·10·15·20·30T(`thick-presets`) | 치수 두께가 없으면 요약에 "두께 5T", 두께 칸에 "(예전 값)" |
| 스카시 분류 몸통 두께·재질·도색 ↔ 스카시 구성 요소 | 몸통에서 없앰(시공 보조 부속품만 남음), 치수 두께 칸도 숨김(스카시 두께가 있음) | 읽을 때 스카시 카드로 옮김 |
| 포맥스 `UV 시트 부착` ↔ 시트 구성 요소 | 없앰 | 켜져 있으면 UV 출력 시트 카드 |
| 복합판 `마감(실사/시트/도색)` ↔ 시트 구성 요소·도색 | 없앰, 도색은 바로 | 실사 → UV 출력 시트, 시트 컷팅 → 커팅 시트 |
| 프레임 액자 `출력(실사/시트)` ↔ 시트 구성 요소 | 없앰 | 실사 → UV 출력 시트, 시트 → 커팅 시트 |
| 갈바·파이프 간접 `간접조명`, 트러스 `조명` ↔ 상단 조명 | 없앰 (상단 조명: 투광등·트러스 바 간접·트러스 타공) | 요약에 "간접조명 …" |
| 시트 분류 시트 칩·시트 옵션 ↔ 시트 카드 | 카드로 | 읽을 때 카드로 |
| 채널 `글자 높이` ↔ 글자 객체 높이 | (이미) 카드에선 글자 객체 높이만 | — |

견적: 조합형 분류는 시트도 구성 요소로만 계산(옛 시트 목록과 이중 계산 없음). 주의: 수동 금액을 넣은 시트 분류 줄은 줄 키가 `:sheet:` → `:part:` 로 바뀌어 다시 입력해야 할 수 있음.

## 데이터 (`core/model.ts`, `core/parts.ts`)
```ts
SignPart { id, kind: 'channel' | 'scashi' | 'sheet', type, options?, on?, items: PartItem[] }
//  type = 채널 제품(ch-front·ch-halo·…) / 스카시 제품(ch-rubber·sc-titan·ch-scashi) / 시트(sh-cut·sh-print·sh-frost)
//  on   = 시트를 올릴 곳: 'frame'(프레임 면) 또는 채널 구성 요소 id(그 채널 앞면)
PartItem { id, kind: 'text' | 'image', text?, count?, x, y, h, w?, image? }
//  위치 x·y = 간판 중앙 기준 mm (x 오른쪽 +, y 위 +), h = 글자 높이·그림 높이, w = 그림·시트 가로
//  image = { sourceId, page } (디자인 파일) 또는 { assetId, name } (직접 올린 그림)
```
- `parts` 는 규격 필드(연결된 사인물이 공유, `SPEC_FIELDS`).
- **옛 데이터 변환**(`partsOf`): `parts` 가 없으면 읽을 때 만든다 — 채널 옵션 + 문구 → 채널 구성 요소 + 글자 1개(채널 세부 옵션, 글자 높이 = 채널 글자 높이 > 간판 높이, 글자수 지정), 스카시 부착 → 스카시(옵션 이름을 스카시 것으로), 시트 → 시트(프레임 면, 시트 옵션), 옛 채널 제품 → 채널. 2026-10-16 부터 모든 조합형 분류에 적용(`partKindsFor`) — 스카시 분류는 스카시 카드, 시트 분류·포맥스·복합판·프레임 액자의 시트는 시트 카드.
- **처음 고칠 때 저장**: 설정 창에서 구성 요소를 고치면 `parts` 로 저장하고 옛 채널·스카시·시트 옵션과 `sheetIds` 를 지운다.

## 견적 (`core/quote.ts`)
- 채널·스카시: 구성 요소마다 글자 객체의 (글자수 × 높이 cm × 원/자·cm) 합. 글자수 = 객체의 글자수 지정 > 글자에서 셈(공백 제외). 객체가 하나면 예전과 같은 문구("n자 × 높이 hmm × …"), 여럿이면 `"바로바로" 4자×600mm + "정육점" 3자×300mm × …`.
- 시트: 크기(가로·높이)가 있는 객체 면적 합, 없으면 간판 면적(도형 기준).
- 간판 분류에서는 `sheetIds` 대신 시트 구성 요소로만 계산.

## 화면 (`ui/PartsEditor.svelte`)
- 설정 창 맨 위는 **사인물 전체 치수**(가로·세로·두께, `size-section`; 2026-10-16 사용자: "치수가 가장 아래있어. 사인물 전체 치수는 최상단에"), 그 아래 종류·모양·몸통 옵션.
- 간판 분류의 설정 창: 몸통 옵션 아래 **구성 요소**(`parts-section`) — [+ 채널] [+ 스카시] [+ 커팅 시트] [+ UV 출력 시트]. 몸통 옵션의 채널·스카시 선택, 시트 칩, 문구 칸, 채널 글자수 칸은 구성 요소 카드로 옮겨져 숨김.
- 카드(`part-card`): 세부 종류(`part-type`), 시트는 올릴 곳(`part-on`: 프레임 면 / 각 채널 앞면), 옵션(`part-option-<key>`, `partOptionFields`: 채널 = 채널 세부, 스카시 = 두께·재질·도색(+ 표면 마감·문자), 시트 = 시트 공통 + 시트별), 삭제.
- 내용 객체: [+ 글자] [+ 그림]. 글자: 글자(`item-text`)·글자수(`item-count`, 비우면 자동)·높이·X·Y. 그림: 디자인 파일 페이지(`item-image-source`) 또는 그림 올리기(`item-image-file`), 높이·가로·X·Y. 새 객체는 간판 중앙(0, 0), 높이 300mm.
- 요약·주문서: 구성 요소마다 `이름 "글자" 높이mm … 그림 n` + 옵션 값(주문서는 기본값까지). 주문 JSON 품목에 `parts`(종류·이름·올릴 곳·옵션(기본값 채움)·객체).

## 재질 객체 · 도색 객체 (`core/materials.ts`, 2026-10-16)
사용자: "재질객체에 스텐, 철, 알루미늄 여기에 도색 객체를 추가해 사용한다. 체널, 스카시, 도색이 필요한 곳에 도색 객체를 넣는다. 체널 전광의 경우 pc판도 선택할 수 있다. 조합 가능한 건 객체를 구성하고 추후 제공되는 자제를 공급업체별로 구성하려한다."
- **재질 객체**(`material()` in `options.ts`): 재질 선택 + 도색 가능한 재질이면 도색 객체. 재질 목록 `MATERIALS`: 스텐 `stain` · 철 `iron` · 알루미늄 `alu` · 갈바 `galva`(도색 가능) · 텐션 천 `tension`(도색 없음). 채널 앞면 판 `FACE_MATERIALS`: 아크릴 `acrylic` · PC판 `pc`.
- **도색 객체**(`paint()`): 색상 체계(도색 없음 기본 / PANTONE / RAL / KCC) → 고르면 컬러코드 · 광택(유광/반광/무광). 키 `<prefix>System·Code·Gloss`.
- 쓰는 곳: 간판 프레임 재질(갈바·트러스·파이프 간접: `frameMat` + `framePaint*`), 갈바 판 도색(`paint*`), 돌출·복합판 도색, 채널 **측면 재질**(`chSideMat`: 알루미늄/스텐/철/갈바) + 측면 도색(`body*`), 채널 **앞면 판**(`chFace`: 아크릴/PC판, 전광·전후광만), 스카시 도색(`paint*`), 간판에 붙인 스카시 도색(`scPaint*`).
- **공급업체 자재(계획)**: 옵션 값은 이름으로 저장하고 재질 id 는 나중에 공급업체별 자재(품목 코드·단가)를 붙일 자리입니다(예: 한울 품목 코드 → [../product/supplier-hanwool.md](../product/supplier-hanwool.md)).

# 컨펌 — 진행 동의(사인물별) · 완료 사진첩 · 참고 이미지 (설계, 2026-10-22)

## 요약
사용자(2026-10-22): "컨펌은 사진뷰어와 같은데 가장 상위 단계가 보이고 사인물에 체크하면 진행하는것이다. 그리고 컨펌은 진행동의와 완료로 탭을 구분하고 완료는 완료 사진첩이다. 최근 고객이 ai로 이미지를 제시하는 경우가 많은데 이건 어디에 담으면 좋을까?"

작업 탭 [사진보드 · 디자인 · 사인물리스트 · **컨펌**]의 컨펌을 **사진 뷰어**로 만든다. 안은 **[진행 동의 | 완료]** 두 탭.

## 상태
| 단계 | 내용 | 상태 |
|---|---|---|
| C1 | 컨펌 = 사진 뷰어(사진마다 가장 앞선 단계), [진행 동의] 탭 — 사인물별 체크 = 진행 | 계획 |
| C2 | [완료] 탭 = 완료 사진첩(시공 후 사진, 현장 사진과 따로) | 계획 |
| C3 | 참고 이미지(고객 AI 이미지 등) 모음 — 디자인 탭, 사인물 연결, 견적 요청 첨부 | 계획 |

## 진행 동의 (C1)
- **사진 뷰어**: 사진을 한 장씩 크게 넘겨 본다(휴대폰은 밀어서). 사진마다 그 사진의 사인물을 **가장 앞선 단계**로 — 3D 합성이 있으면 3D, 없으면 디자인(파일 연결된 2D), 없으면 러프 디자인(2D), 그것도 없으면 실측(외곽선·치수). 단계 이름을 사진 위에 작게("3D", "디자인", "러프").
- **사인물별 체크 = 진행**: 사진 아래(또는 사진 위 사인물 자리)에 사인물마다 체크 — 체크하면 그 사인물 **진행 동의**(누가·언제, 그때의 내용 해시). 다 체크하면 "전체 진행". 체크 뒤 그 사인물이 바뀌면 다시 확인 필요(지금의 승인·재승인 규칙을 사인물 단위로).
- **누가 체크**: 고객(제안 링크로 들어온 보기 권한)이 체크하고, 간판집은 체크 상태를 본다(간판집이 대신 체크하면 "간판집 기록"으로 표시). 고객은 문서를 고칠 수 없으므로 서버 RPC(지금의 승인 `addApproval` 처럼).
- **지금 승인과의 관계**: 프로젝트 전체 [이걸로 할게요]는 "모든 사인물 체크"와 같다 — 사인물별 체크로 넓힌다. 요청판의 [확정](간판집 고르기)은 따로 그대로.
- 간판집 화면(작업 탭 컨펌)과 고객 제안 페이지가 **같은 뷰어**(간판집은 체크 현황·재확인 필요 표시가 더 보임).

## 완료 사진첩 (C2)
- 시공이 끝난 뒤 올리는 사진 — **현장(실측) 사진과 따로** 모은다(원근·실측 대상이 아님). 사인물에 연결(어느 사인물의 완료 사진인지), 날짜·한 줄 설명.
- 고객 제안 페이지 [완료] 탭에서도 보이고, 간판집 포트폴리오(제안 페이지·견적 요청 응답의 실적)로 쓸 수 있게 둔다.

## 참고 이미지 — 고객의 AI 이미지 등 (C3)
**어디에**: 현장 사진(사진보드)도 디자인 파일(디자인)도 아닌 **"참고 이미지"** 모음을 따로 둔다. 사진보드에 섞이면 실측·원근 대상이 되고, 디자인 파일에 섞이면 최종 디자인으로 오해된다.
- **자리**: 디자인 탭 안 **[참고]** — 프로젝트의 무드보드. 이미지마다 **"이 사인물 참고"**로 사인물에 연결하면 그 사인물 설정 창·러프 디자인 작업 때 옆에 보인다.
- **들어오는 길**: 직접 올리기 · 대화 첨부에서 [참고 이미지로] · **견적 요청할 때 가게 사장이 첨부**(요청서·실측 보기에 같이 보임).
- **구분 표시**: 꼬리표 "참고 · 고객 제공"(AI 생성이면 "AI"), 디자인 리스트·주문서·견적에는 들어가지 않는다.
- 나중: 참고 이미지 위에 러프 디자인을 따라 그리기(반투명 바탕).

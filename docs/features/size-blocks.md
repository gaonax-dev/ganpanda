# 치수 블록 — 같은 크기 사각으로 원근을 정밀하게

## 요약
치수를 넣은 사인물에 **같은 크기의 사각(블록)** 을 더 그려 원근 풀이에 보탭니다. 설정(치수)은 하나, 사각은 여러 개. 블록의 변이 사인물의 변과 함께 축 선이 되어 소실점이 건물 전체에 퍼진 선들로 정해지고, 멀리(2층) 있는 영역의 추정 외삽 오차가 줄어듭니다. 블록은 견적·리스트에 들어가지 않습니다.

사용자(2026-11-03): "같은 크기 사각형으로 나머지 사인물 대략 크기를 정확도 높게하는 방법이 어떤가? … 모서리 대각으로 같은크기 블록을 넣는거야" → "일반 사인물처럼 네모를 그리면 설정이 하나인 사각이 두개가 되고 … 사이즈 빨강 인디케이터 … 정확도가 향상된면 보라색으로" → "치수블록은 핫핑크라인으로". 사인물 선택의 길이 블록(변을 따라 눈금)은 넣지 않음("길이블록은 사인물에서 제외").

## 상태
구현됨 (2026-11-03) — `src/lib/core/blocks.ts`(선·맞음 판정·꼭짓점 붙이기·대각 예측), `src/lib/core/camera.ts`(`CameraSetup.extra`, 최소제곱 소실점), `src/lib/state.svelte.ts`(`blockTarget`·`addBlock`·`updateBlock`·`removeBlock`·`blockFitOf`, 판독에 블록 포함), `src/lib/views/PhotoZone.svelte`(그리기·표시·손잡이), `src/lib/views/BoardView.svelte`([블록] 도구)

## 왜 효과가 있나
1층 사인물 하나는 작고 변이 거의 평행해 소실점이 흔들리고, 그 오차가 2층으로 외삽되며 커집니다. 블록을 2층 근처까지 이어 놓으면 축 선이 사진 전체에 퍼져 소실점·화각이 안정됩니다. 합성 사진 검증(`tests/unit/blocks.test.ts`): 366px 사인물의 꼭짓점을 ±3px 흔들었을 때 2층 창문(참값 1500×1200) 추정이 사인물만으로는 1717×1869, 블록 둘을 더하면 1449×1193.

## 데이터
`SignObject.blocks?: Pt[][]` — 블록마다 외곽 4점(TL,TR,BR,BL, 사진 원본 px). 위치 필드(연결 `sameAs` 때도 자기 것). 지우면 `undefined`. → [../architecture/data-model.md](../architecture/data-model.md)

## 화면
- **[블록] 도구**(`tool-block`, 하단 도구 막대 [사각] 옆): 사진 위 사각·원형 사인물을 골랐고 치수(추정 아님)가 있을 때만 켜진다(`app.blockTarget`). 다른 것을 고르거나 선택을 풀면 선택 도구로 돌아간다.
- **그리기**: 사인물처럼 네모를 끌어 그리면 새 사인물이 아니라 고른 사인물의 블록이 된다(`app.addBlock`). 모서리를 이어 가는 작업이라 그린 뒤에도 도구가 유지된다(Esc·[선택]으로 끝). 블록 도구 중엔 사인물·존이 누르기를 받지 않아 꼭짓점 위에서 시작할 수 있다.
- **대각 예측**(`predictBlock`): 시작점이 그 사인물·블록의 꼭짓점 가까이(화면 14px)이고 원근이 있으면, 그 꼭짓점에 모서리를 맞댄 **같은 크기** 블록을 끌어간 방향(가로 ±·세로 ±)으로 벽 위에 놓고 투영한다. 원근이 없거나 꼭짓점에서 떨어져 시작하면 그린 네모 그대로.
- **표시**(`size-block[data-id][data-index]`): 선은 **핫핑크** `#ff69b4`(`BLOCK_COLOR`), 가운데에 지금 원근으로 잰 크기 **≈가로×세로** 가 **빨강**(`block-size`). 잰 크기가 사인물 치수와 가로·세로 모두 10%(`BLOCK_FIT_TOL`) 안이면 **정확도 향상 = 보라** `#a855f7`(`BLOCK_FIT_COLOR`, `data-fit="1"`, 선·글자). [정보]를 끄면 글자, [구별선]을 끄면 블록이 숨는다(고른 사인물은 보임).
- **고른 사인물의 블록**: 꼭짓점 손잡이(`block-handle`, 끌어 사진의 창틀·줄눈에 맞추기), 블록 안을 끌면 통째로 옮김, 오른쪽 위 **✕**(`size-block-remove`). 모두 ⌘Z.

## 풀이
- `signCameraSetup(quad, widthMm, blocks)` 가 블록의 위·아래 변을 가로(X), 좌·우 변을 높이(Z) 축 선으로 `CameraSetup.extra` 에 넣고, `solveCamera` 는 같은 축의 선이 셋 이상이면 **최소제곱 소실점**(사진 중앙·장변으로 정규화한 좌표에서 Σ(lᵢ·v)² 최소 = 산포 행렬의 최소 고유벡터, 야코비 회전)으로 푼다. 둘이면 전처럼 교점.
- **자동 흐름**(치수 입력과 같은 `watchSizes` → `autoLength`): 블록을 그리거나 옮기면 0.7초 뒤 그 사인물 + 블록으로 원근을 다시 잡는다(`autoCameraFrom` — 블록이 있으면 AI 축보다 사인물+블록 우선, `signCameraFit` 로 화각까지). 사람이 원근 창에서 적용한 원근은 손대지 않는다. [원근 자동 매칭]도 고른 사인물의 블록을 함께 쓴다.
- **판독**(`app.measures`): 블록은 치수 없는 영역(`id#b{i}`)으로 함께 재서 지금 원근으로 본 크기를 얻는다(보라 판정용). 축척 보정(치수 입력 영역의 중앙값)에는 넣지 않는다 — 블록은 검사 대상이지 기준이 아니다.
- 블록이 어긋난 채(핫핑크) 남으면 다른 평면(돌출·물러난 벽)이거나 잘못 그린 것이다. 블록이 맞지 않아도 자동 원근은 사인물 + 블록으로 풀리므로, 틀린 블록은 지우는 것이 맞다.

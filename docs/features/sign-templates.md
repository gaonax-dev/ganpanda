# 완성품 퀵 — 사진 고르고 칸 채우기 (2026-10-23)

사용자(2026-10-23): "인간적인 결정구조는 간판 -> 갈바, 후렉트, 체널간판, 후광간판, 후렉트체널 -> 배경색, 글자색 -> 내용 / 스카시 -> 아크릴 -> 아크릴색(도색), 글자색 -> 내용. 이건 퀵 선택방식이다. 여기에서 채널간판은 이전에 조합한 어떤것이다."
→ "퀵에서는 간판을 선택하고 사진중에 하나를 선택하는데 현재 체널만 있다. 해당 상황은 완전제품이다. 그래서 완성된 상태에 따라 글자가 2가지 3가지가 될수 있어. 그냥 이전의 완성품 구성에 변경 가능한 필드를 하나씩 대입해서 완성하는 거이야. 중간에 멈추면 거기까지 완성이다."

## 동작 — 구현됨
- 영역을 그리고 **분류**(간판)를 고르면, 구성 요소가 아직 없는 새 사인물은 **완성품 사진**(`tpl-pick`)이 펼쳐진다. 데스크톱 패널은 격자, 휴대폰 빠른 막대는 가로로 넘기는 줄(`compact`).
- **프레임간판은 다시 조명 · 비조명 · 돌출**(2026-10-27 사용자가 보낸 한울상사 분류 "조명 프레임 간판 · 비조명 프레임 간판 · 돌출 프레임 간판" → "진행해줘"): 프레임간판을 고르면 카드 세 장(데스크톱 한 줄 셋, 휴대폰은 설명 없이 작은 카드 셋) → **조명** = 후렉스 · 후렉스+채널, **비조명** = 갈바 · 갈바+채널, **돌출** = 돌출 간판(새 완성품: 몸통 `board-protrude`, 앞면 흰색, UV 출력 글자 빨강, 그림 `public/sign-types/protrude.svg`). [‹ …]은 한 단계씩 위로. 채널간판 15종은 한울상사 LED 채널간판 10종을 모두 포함(이름도 같음)해 그대로. 한울상사 사진은 쓰지 않는다(다른 회사 상품 사진) — 직접 그린 그림. `signTemplates.ts FRAME_SUBS · subsFor`.
- **간판은 먼저 프레임간판 / 채널간판**(2026-10-27 사용자: "간판 종류 선택에 프레임간판, 체널간판 으로 먼저 분류를 하고 세부 사항으로 간다"): 간판 분류는 큰 카드 두 장(`tpl-family`, 대표 그림·한 줄 설명)을 먼저 보이고, 고른 갈래의 완성품만 펼친다 — **프레임간판** = 갈바·후렉스·후렉스+채널·갈바+채널(판 몸통), **채널간판** = 채널 15종(몸통 없음, 벽에 바로). 위 [‹ 채널간판](`tpl-family-back`)으로 다시 고르기, [완성품 사진에서 고르기]로 다시 열면 갈래부터. 갈래가 없는 분류(스카시 등)는 바로 사진. 데이터 모델은 그대로(채널은 구성 요소 — 2026-10-15 결정 유지), 고르는 순서만 나눴다(`signTemplates.ts SIGN_FAMILIES · familiesFor · templatesFor(g, family)`).
- 사진을 누르면 그 **완성품 구성이 통째로** 들어간다(몸통·옵션·구성 요소·글자). 그다음 **바꿀 칸**(`tpl-step`, "1/4 몸통(옆면)색")을 하나씩 — 색은 견본 + 컬러 피커, 글자는 입력(Enter = 다음). **칸마다 바로 저장**.
- **[완료]**(`tpl-done`)나 다른 곳으로 가면 **거기까지 완성** — 안 채운 칸은 완성품 값 그대로(글자 기본 "간판").
- 이미 구성된 사인물은 저절로 펼쳐지지 않고 **[완성품 사진에서 고르기]**(`tpl-open`). 고르면 구성이 그 완성품으로 바뀐다(되돌리기 한 번).
- 세부는 그 뒤 지금처럼 칩·설정 창에서.

## 구조
- `core/signTemplates.ts`: 완성품 정의 = 데이터 `{ 분류, 몸통 productId, 몸통 옵션, 구성 요소들(종류·묶음·옵션·재료 층·글자 비율), 색 칸(몸통 도색 / 구성 요소 도색 / 구성 요소 미리보기 색) }` → `{ apply(o), slots(o) }`. 칸 = `{ label, kind: color | text, read, write }` — write 는 그 칸만 바꾸는 패치(구성 요소 저장 `commitParts`). 글자 칸은 구성 요소의 글자 객체마다 자동.
- 칸 순서 = 사람의 결정 순서: **색(배경·몸통 → 글자 → 캡) → 글자 내용**. 완성품에 있는 색만 칸이 된다(미러·티타늄 마감은 몸통 색 칸 없음). 글자가 여럿이면 "글자 1·2…".
- UI `ui/TemplateQuick.svelte` — `ObjectPanel`(분류 아래)·`QuickBar`(종류 셀렉터 아래)가 같이 쓴다.

## 완성품 목록
갈바·후렉스·스카시는 아직 사진이 없어 **그림**(`public/sign-types/*.svg`)으로 — 사진이 오면 바꾼다(2026-10-23 사용자: "갈바나 후렉스들도 같은 칸에 있어서 선택 가능하게").

| 분류 | 완성품 | 구성 | 칸 |
|---|---|---|---|
| 간판 | 갈바 간판 | 갈바(흰 도색) + 커팅 시트 글자 | 배경색(갈바 도색) → 글자색(시트) → 글자 |
| 간판 | 후렉스 간판 | 후렉스(흰 배경) + 출력 글자 | 배경색(후렉스 배경) → 글자색(출력) → 글자 |
| 간판 | 후렉스 + 채널 | 후렉스(남색 배경) + 전광 채널 | 배경색 → 몸통(옆면)색 → 글자(앞면)색 → 글자 |
| 간판 | 갈바 + 채널 | 갈바(진회색) + 전광 채널 | 배경색 → 몸통(옆면)색 → 글자(앞면)색 → 글자 |
| 간판 | 채널 15종(채널 라이브러리 사진) | 몸통 없음(벽 부착) + 그 채널 묶음 + 글자 1개(간판 높이 80%) | 묶음에 있는 몸통·앞면·캡 색 → 글자 |
| 스카시 | 아크릴 스카시 | 아크릴 8T, 옆면 도색 + 앞면 도색 | 아크릴색(옆면) → 글자색(앞면) → 글자 |

- 분류를 바꾸면 그 분류의 완성품부터 다시(스카시 분류는 빈 스카시가 기본으로 있어 "새 사인물" = 글자·그림이 아직 없음).
- 2D 색·글자는 보드의 2D 단계에서 보인다(기본 보기는 외곽선).

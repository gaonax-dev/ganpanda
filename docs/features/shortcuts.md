- 마우스 휠 판별: `wheelDeltaY`가 ±120의 배수이고 가로 이동이 없으면 마우스 휠로 봅니다.
- 배율: `1 − deltaY × 감도`. 감도는 픽셀 단위 0.005, 줄 단위 0.1입니다. Windows에서는 핀치(|deltaY| < 50) ×2(`PINCH_ZOOM_SENSITIVITY`), 마우스 휠 ×0.2(`WHEEL_ZOOM_SENSITIVITY`)를 곱합니다.
- 브라우저 자체 확대(Ctrl+휠, ⌘ +/−/0)와 가로 스와이프 뒤로가기는 막습니다: `window` 캡처 단계 휠 리스너(가로 우세·Ctrl 이면 preventDefault) + CSS `overscroll-behavior: none`(html·body) / `contain`(모든 스크롤 영역). 2026-10-15 사용자 제보(창을 휴대폰 폭으로 줄였다 돌아온 뒤 두 손가락 이동에 페이지 이동)로 CSS 차단을 추가.

- 키보드 확대·축소 기준점: 선택한 사인물이 화면에 보이면 그 중심, 아니면 화면 중심 (xlpop과 동일).

## 규칙
- **조합 문자열**: `Mod+Shift+R` 형식. `Mod` = 맥 ⌘ / 그 외 Ctrl. 수식키 순서는 Mod, Ctrl, Meta, Alt, Shift.
- **물리 키 기준**: 글자는 `KeyboardEvent.code`로 인식합니다. 한글 입력 상태에서 R을 눌러도(`ㄱ`) R로 인식됩니다.
- 숫자패드 `+`/`-`는 일반 `+`/`-`와 같게 취급합니다.
- 저장: `localStorage`의 `ganpanda.keymap` (기기별). 저장값에 없는 동작은 기본값으로 채우고, 모르는 동작이나 손상된 값은 무시합니다 (`mergeKeymap`).
- 같은 키를 두 동작에 지정하면 설정 화면에 충돌 경고가 뜨고, 목록에서 앞에 있는 동작만 실행됩니다.

## 설정 화면 (`src/lib/ui/Settings.svelte`)
- 닉네임 메뉴의 **⚙ 설정**으로 엽니다(2026-10-22, 로그인 전에는 상단 ⚙). **탭**(2026-10-21 사용자: "설정을 내용별로 탭으로 분리해줘", `settings-tab-<id>`): **계정**(구독·사용량·비밀번호) · **멤버** · **사양 사전**(내 규칙·용어집·지역) · **요청 받기**(요청판이 켜져 있을 때만) · **표시** · **단축키**(아래 내용 + [모두 기본값으로]). 로그인 전에는 표시·단축키만. 처음 탭은 계정(로그인 전엔 표시)이고 `app.settingsOpen = '<탭>'`으로 특정 탭을 바로 열 수 있다(홈 "받은 요청"의 설정 링크 → 요청 받기). 동작마다 [변경](키 하나로 교체), [＋](키 추가), [↺](이 동작만 기본값), 키 칩의 ×(삭제)가 있습니다.
- 키 입력 대기 중 Esc는 취소입니다. 수식키만 누르면 계속 기다립니다.
- [모두 기본값으로]로 전체 초기화합니다.

## 복사·붙여넣기·복제 (2026-10-15 사용자: "카피 페이스트 복제등이 필요하다")
- **복사**(`app.copySelected`, `core/clipboard.ts` `clipOf`): 선택한 사인물의 규격(종류·시트·치수·두께·문구·글자수·입체·옵션·메모·디자인)과 모양(외곽선·다각형·둥글기)을 탭 안의 클립보드에 담습니다. 다른 사진의 같은 사인물(연결)이면 원본 규격으로 담고 연결은 끊습니다. 평면도 자리·디자인 이력·대화는 담지 않습니다. 다른 프로젝트로 옮겨 붙일 수 있습니다(같은 탭).
- **붙여넣기**(`pasteClipboard`, `pastedObject`): 선택한 사인물의 사진 > 복사한 사진 > 첫 사진에 붙입니다. 이름은 "… 복사", 붙일 때마다 사진 폭의 3%씩 오른쪽 아래로 비키고 사진 밖이면 안으로 들입니다. 크기가 다른 사진이면 비율대로 옮기고, 그 사진의 원근에 맞춘 정면 축·박스 방향·돌려 세우기는 뺍니다. 디자인 소스가 없는 프로젝트면 디자인을 뺍니다. 붙인 사인물이 골라지고 ⌘/Ctrl+Z 로 되돌립니다.
- **복제**(`duplicateSelected`): 클립보드를 건드리지 않고 바로 옆에 하나. 사인물 설정 창의 [복제](`duplicate-sign`)로도 — 휴대폰에서도 쓸 수 있습니다.
- **Alt/Option + 끌기**(`duplicateInPlace`, 2026-10-17 사용자: "alt/option 누르고 이동하면 복사"): 사진 위 사인물이나 평면도 카드를 Alt 를 누른 채 끌면 **같은 자리에 복사본**이 생기고(비킴 없음, `pasteClip(c, 0)`), 그 복사본이 따라 움직입니다. 원본은 그대로. 일러스트레이터·피그마와 같은 손버릇.
- 편집 권한이 있을 때만 붙여넣기·복제. 입력칸에 커서가 있으면 브라우저의 글자 복사·붙여넣기 그대로입니다.

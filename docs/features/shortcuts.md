# 화면 조작과 단축키

## 요약
화면 조작은 **xlpop 캔버스와 같게** 맞췄습니다(`xlpop/web/components/worksheet/CanvasViewport.ts`, `SiteView.tsx`). 키보드 단축키는 **설정 → 단축키**에서 바꿀 수 있습니다.

## 상태
구현됨 (2026-10-13)

## 마우스·트랙패드 (고정, `src/lib/core/wheel.ts`)
| 입력 | 동작 |
|---|---|
| 마우스 휠 | 커서 기준 확대·축소 |
| Ctrl + 휠, 트랙패드 핀치 | 커서 기준 확대·축소 |
| 트랙패드 두 손가락 스크롤 | 이동 |
| 빈 곳 드래그, 가운데 버튼 드래그 | 이동 |

- 마우스 휠 판별: `wheelDeltaY`가 ±120의 배수이고 가로 이동이 없으면 마우스 휠로 봅니다.
- 배율: `1 − deltaY × 감도`. 감도는 픽셀 단위 0.005, 줄 단위 0.1입니다. Windows에서는 핀치(|deltaY| < 50) ×2(`PINCH_ZOOM_SENSITIVITY`), 마우스 휠 ×0.2(`WHEEL_ZOOM_SENSITIVITY`)를 곱합니다.
- 브라우저 자체 확대(Ctrl+휠, ⌘ +/−/0)와 가로 스와이프 뒤로가기는 막습니다.

## 키보드 기본값 (`DEFAULT_KEYMAP`, `src/lib/core/keymap.ts`)
| 동작 | 기본 키 |
|---|---|
| 확대 | ⌘/Ctrl + `=`, ⌘/Ctrl + `+` (맥은 ⌃도 가능) — 1.25배 (`KEY_ZOOM_STEP`) |
| 축소 | ⌘/Ctrl + `-` |
| 전체 보기 | ⌘/Ctrl + `0` |
| 화면 이동 | 스페이스를 누른 채 드래그 (사진·도형 위에서도 이동) |
| 선택 도구 | V |
| 사각 영역 | R |
| 원형 영역 | O |
| 핀 (위치 코멘트) | P — viewer 도 사용 가능 |
| 자동 분리 (AI) | A |
| 선택한 사인물 삭제 | Delete, Backspace |
| 실행 취소 | ⌘/Ctrl + Z (편집 권한만) |
| 다시 실행 | ⌘/Ctrl + ⇧ + Z, ⌘/Ctrl + Y |
| 선택 도구 / 입력 종료 | Esc (고정, 변경 불가) |

- 키보드 확대·축소 기준점: 선택한 사인물이 화면에 보이면 그 중심, 아니면 화면 중심 (xlpop과 동일).
- 확대·축소·이동 단축키는 마우스가 캔버스 위에 있을 때만 동작합니다.
- 입력칸에 커서가 있을 때는 단축키가 동작하지 않습니다.

## 규칙
- **조합 문자열**: `Mod+Shift+R` 형식. `Mod` = 맥 ⌘ / 그 외 Ctrl. 수식키 순서는 Mod, Ctrl, Meta, Alt, Shift.
- **물리 키 기준**: 글자는 `KeyboardEvent.code`로 인식합니다. 한글 입력 상태에서 R을 눌러도(`ㄱ`) R로 인식됩니다.
- 숫자패드 `+`/`-`는 일반 `+`/`-`와 같게 취급합니다.
- 저장: `localStorage`의 `ganpanda.keymap` (기기별). 저장값에 없는 동작은 기본값으로 채우고, 모르는 동작이나 손상된 값은 무시합니다 (`mergeKeymap`).
- 같은 키를 두 동작에 지정하면 설정 화면에 충돌 경고가 뜨고, 목록에서 앞에 있는 동작만 실행됩니다.

## 설정 화면 (`src/lib/ui/Settings.svelte`)
- 상단 ⚙ 버튼으로 엽니다. 동작마다 [변경](키 하나로 교체), [＋](키 추가), [↺](이 동작만 기본값), 키 칩의 ×(삭제)가 있습니다.
- 키 입력 대기 중 Esc는 취소입니다. 수식키만 누르면 계속 기다립니다.
- [모두 기본값으로]로 전체 초기화합니다.

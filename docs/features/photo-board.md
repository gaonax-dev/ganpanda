# 사진 보드

## 요약
건물 사진을 무한 캔버스에 구역으로 놓고, 사진 위에 사인물 영역을 표시하는 화면입니다.

## 상태
구현됨 (사각·원형). AI 자동 분리(SAM)는 계획입니다.

## 동작
- **하단 도구 막대**(2026-10-20 사용자: "하단 툴바 위치를 변경한다. 자동은 삭제 존,undo,redo, 사각,원(타원으로 변경), 사진, 전체보기 / 언두 리두 아이콘 일반적인 모양으로 사진은 사진기 아이콘으로"): 선택·말풍선(목록에 없어 앞에 둠) | **존 · 실행 취소 · 다시 실행 · 사각 · 타원 · 사진 · 전체 보기** · 배율. 실행 취소·다시 실행은 휘어진 화살표 아이콘, 사진은 사진기 아이콘, 원형은 "타원". ✨ 자동 단추는 뺐다(단축키 A 는 남김). **휴대폰**에서는 아이콘이 같은 너비로 자리를 나누고 구분선은 없다(2026-10-20 "툴바 아이콘 모바일에서 균등하게 자리 가지게해주고 구분은 제거").
- **사진 추가**: 도구 막대의 사진기 아이콘(`tool-photo`) 또는 끌어다 놓기. 기존 사진 오른쪽에 이어 붙이고 전체가 보이게 맞춥니다.
- **사진 이름**(2026-10-20 사용자: "이미지 이름이 모두 같아 사진 올리면 프로젝트면+_img_#으로 이름올려줘 #은 번호"): 올린 사진은 파일 이름 대신 **프로젝트 이름_img_번호**(`core/photoName.ts` `nextPhotoName`). 번호 = 그 프로젝트 사진 이름의 `_img_번호` 중 가장 큰 것 + 1 — 지운 사진 번호를 다시 쓰지 않고, 프로젝트 이름을 바꿔도 이어진다. 프로젝트 이름이 비면 "사진". 이미 올린 사진 이름은 그대로.
- **사진 이동·삭제**: 사진 위쪽 이름 바를 끌어 이동, ✕로 삭제(확인 후, 오브젝트·대화도 함께 삭제).
- **영역 그리기**: 사각(T, 2026-10-15 R → T)·원형(O) 도구로 드래그. 화면 기준 8px보다 작은 드래그는 무시합니다. 그린 뒤에는 선택 도구로 돌아가고 오브젝트 패널이 열립니다.
- **원형 = 둥근 사각형** (2026-10-14 사용자 결정: "원형은 사각형을 기본으로 라운드로 제어, 이미지 맵핑이 되게"): 원형 도구는 `shape: 'rect', corner: 0.5`(짧은 변 대비 반지름 비율)로 만듭니다. 설정 창 "모양"의 **모서리 둥글기** 슬라이더(`corner-ratio`, 0~50%)로 사각 ↔ 둥근 사각 ↔ 원·알약을 조절합니다. 윤곽은 `roundedInQuad`(정면 둥근 사각형을 원근 사각형에 투영), 디자인은 사각형 그대로 입혀지고 그 윤곽으로 잘립니다(`clip-path`). 전개도는 `inset(0 round r)`, 견적 면적은 w·h−(4−π)r², 실사 보기는 둥근 사각형을 밀어낸 박스(`lightboxGeometry`)에 면 이미지를 맞춥니다. 옛 `shape: 'ellipse'` 데이터는 타원으로 계속 보이고, 슬라이더를 움직이면 둥근 사각형으로 바뀝니다.
- **원근 맞추기**: 선택한 영역의 모서리 핸들 4개를 끌어 사진 속 실제 모서리에 맞춥니다. 영역 안쪽을 끌면 통째로 이동합니다. 원형은 이 사각형에 내접한 타원(원근 반영)으로 그려집니다.
- **라벨**: 이름 · 입력 치수(또는 `≈추정 치수`). 실측 경고가 있으면 ⚠ 표시.
- **미실측 수**(2026-10-21 사용자: "실측타이틀에 미실측 수량 넣어줘 가로 세로 미입력수"): [실측] 단추에 가로·세로를 아직 넣지 않은 사인물 수 배지(`unmeasured-count`, `app.unmeasuredCount` — 원본만, 연결 영역은 같은 사인물). 다 넣으면 사라진다. 마우스를 올리면 "미실측 n개".
- **단계** 상단 [실측 | 2D | 3D] (2026-10-17 사용자: "원본 2d 3d 이렇게 해줘. 2d가 현재 보여주는 형식이고 원본은 실측만 나오게" → 2026-10-18 "원본 2D 3D를 실측, 2D, 3D 으로 변경"; 코드 값은 `original` 그대로): **실측**(옛 이름 원본) = 사진 그대로 + 외곽선·치수(실측)만. **2D**(기본) = 사인물마다 **바탕**(`sign-fill`: 고른 색·투명도, 없으면 종류 기본 겉모습 `bodyLook`) → **프레임 테**(`sign-frame`: 테가 있는 종류 + 치수 있을 때, 테 폭(mm)만큼 안으로 들어간 고리 — 안쪽 선은 사인물 좌표에서 들어간 사각형을 외곽선 호모그래피로 투영해 원근에서도 폭이 고르다(2026-10-18, 전엔 중심 축소 근사), `frameLook` — 2026-10-17 "3d에서 프레임과 판을 구별하나?"; 평면도 카드에는 테두리를 그리지 않는다 — "정면도들은 테두리를 주지 않는다") → 입힌 디자인 → 글자·그림 겹침을 외곽선 안에 평면으로. **3D** = 보드 전체를 3D 합성 결과로(편집 없음).
- **3D 단계**: 보드 전체를 3D 합성 결과로 봅니다(편집 없음). **렌더링**: 사진 이름 바의 [🎨 렌더링 ✓ / 🎨 렌더링] → 이 사진의 디자인 포함 최종 합성 창(주간·야간·PNG) → [render-3d.md](render-3d.md)

- **설정 창(`ObjectSettingsDialog.svelte`, `app.objectSettingsOpen`)**: 세부 종류 선택, 시트, 문구, 치수·글자수, 가로/세로 기준 체크, 실측 경고와 추정값 적용, 입체 보기(3D), 예상 금액 상세, 사인물 삭제. Esc·바깥 클릭·닫기로 닫힙니다. 다른 사인물을 선택하면 닫힙니다(`selectObject`).
- **분류 규칙(`catalog.ts` `categoryOf/productsOf/defaultProductFor`)**: 제품이 있으면 그 분류 — 보드·전광·후광·갈바 채널 = 간판, 스카시·고무 스카시 = 스카시. 제품 없이 시트만 = 시트. 분류를 고르면 기본 제품으로 시작합니다(간판 → 후렉스, 스카시 → 고무 스카시, 시트 → 제품 없이 시트 컷팅 `sh-cut`; 2026-10-15: 시트가 하나도 없으면 분류가 비어 보여서). 데이터 모델은 바뀌지 않았습니다(`productId`, `sheetIds`).
- E2E 는 `openObjectSettings(page)` 헬퍼로 설정 창을 연 뒤 세부 항목(`width-mm` 등)을 다룹니다. 창이 열려 있으면 뒤의 보드·패널은 눌리지 않으므로 다른 조작 전에 `close-object-settings` 로 닫습니다.

## 여러 사진의 같은 사인물 (2026-10-14 사용자 요청)
- 사용자: "여러 사진에 같은 사인물을 표시한다. 같은 규격·같은 소스로 표현하고 견적에도 하나만 나와야 한다… 같은 사인물이라고 지정(기존 사인물로 연결)하면 같은 속성창이 뜨고, 지정한 디자인이 맵핑 또는 3D 오브젝트로 나오게."
- 두 번째 사진에 영역을 그리면 패널 맨 위에 **"기존 사인물과 같은 것? [선택]"**(`link-select`, 다른 사인물 목록 "이름 · 사진"). 고르면 `project.linkObject` → 그 영역은 원본의 규격(이름·분류·제품·시트·치수·문구·디자인·입체 설정)을 그대로 보여 주는 **같은 속성창**이 되고, 대화도 원본 것을 봅니다. 라벨에 **⇄** 표시(`sign-linked`), 패널에 "⇄ 같은 사인물 · N곳에 표시"와 다른 사진으로 가는 버튼(`link-info`), [연결 해제](`unlink`). 리스트에서 **[사진에 올리기]**로도 연결된 영역을 만들 수 있습니다 → [sign-list-quote.md](sign-list-quote.md).
- 선택하면 **다른 사진의 같은 사인물도 하이라이트**됩니다(점선 테두리, `data-same`, 핸들은 선택한 영역에만 — 사용자: "컨트롤러 없이"). `app.sameAsSelected`.
- 속성창에서 규격을 고치면 원본이 바뀌어 모든 사진에 반영. 영역 위치·원근·가로/세로 기준 체크는 사진마다 따로.
- 치수를 한 번 넣으면 카메라 설정이 없는 사진에서는 연결된 모든 사진의 기준 영역이 됩니다(실측 판독은 풀린 규격으로 계산). 그 사진의 추정이 크게 어긋나면 경고는 그 영역에 뜹니다.
- 리스트·견적·견적서·UV 목록에는 원본 하나만(`app.signs`). 실사 보기는 사진마다 같은 규격·같은 디자인으로 합성(채널 + 문구 = 3D 글자, 보드 = 디자인 맵핑).
- 데이터·규칙 → [../architecture/data-model.md](../architecture/data-model.md) `sameAs`. 코드 `src/lib/core/link.ts`, `Project.linkObject/unlinkObject/removeObject`. 테스트 `tests/unit/link.test.ts`, `tests/e2e/link.spec.ts`.
- 다음 단계 후보: 리스트 뷰의 사인물을 사진으로 끌어다 놓아 연결, 존 = 벽면(사진마다 벽면 평면)과 묶기.

## 보드 위 평면도 카드와 보드 사인물 (2026-10-15 사용자 시나리오)
사용자: "사진에 직접 넣고 사용자가 사이즈를 직접 입력하면 사진 하단에 사인물이 평면도로 생성된다. 외각(보드 빈 곳)에 사인물을 생성하면 바로 생성된다. 이후 사진에 있는 사인물과 연결한다."
- **평면 구역**(`BoardCard.svelte`, `board-card`, 2026-10-15 사용자: "같은 사인물이 중복으로 발생했다. 평면 사인물은 배치를 할 수 있어야 한다. 해당 배치는 리스트 뷰에서도 적용"): 모든 사진 아래(`flatOrigin`: 가장 낮은 사진 바닥 + 80px, 가장 왼쪽 사진 x)에 **리스트 뷰와 같은 목록·같은 배치**로 평면도 카드를 놓습니다 — `app.flatCards`(치수가 있는 **원본** 사인물, 연결 복사본은 제외 → 사진이 여럿이어도 카드는 하나) + `app.flatPlaced`(`layoutList`, `listX/listY` mm). 보드 좌표 = 원점 + mm × **축척**(`listToBoard/boardToList`, 기본 0.1px/mm). **평면 구역 전체 크기**(2026-10-17 사용자: "평면도 전체 사이즈 조절 가능하게"): 라벨 옆 [−] 100% [+](`flat-scale-down/up/value`, ×1.25) 또는 구역 오른쪽 아래 손잡이(`flat-handle`)를 끌어 비율대로. 프로젝트 설정 `settings.flatScale`(px/mm, 0.02~0.5, `clampFlatScale`)에 저장되어 모두에게 같고, mm 배치(`listX/listY`)·리스트 뷰·PDF 는 바뀌지 않는다 — 보드에 그리는 크기만. **평면 구역 이동**(2026-10-17 사용자: "왼쪽 상단에도 버튼이 있으면 좋겠다. 이건 이동"): 구역 왼쪽 위 ✥ 손잡이(`flat-move`)를 끌면 구역 전체가 옮겨지고 `settings.flatOffset`(보드 px)에 저장 — 원점 = 사진 아래 기본 원점 + 오프셋(`flatOrigin(photos, gap, offset)`). 역시 mm 배치는 그대로. 카드를 **끌면 `listX/listY` 가 바뀌어 리스트 뷰도 같은 자리**. 얼굴은 사진 영역을 정면 보정한 모습(`core/cardFace.ts`) 위에 **바탕색**(`card-fill`, 2D 무대 `sign-fill` 과 같은 `bodyLook` 색·투명도, 2026-10-17 "정면도에도 배경색 나오게") → 디자인 → 구성 요소 (프레임 테두리는 없음). 라벨 제목 **왼쪽에 배지**(`card-badge`, `faceBadge`): 디자인 파일이 연결되면 **디자인**, 몸통 종류(바탕색)나 구성 요소 글자가 있으면 **설정**, 아니면 **원본**(사진 그대로) — 리스트 카드도 같음. 라벨은 이름·가로×세로(×두께)·추정, 연결된 것은 ⇄, 화면에서 40px 보다 좁으면 라벨 숨김. 누르면 그 사인물 선택.
- **보드 사인물**(`board-standalone`, `photoId: ''`, `quad: []`, 위치는 평면 배치 `listX/listY`): 사각(또는 원형) 도구로 **보드 빈 곳**을 끌면 바로 생깁니다. 끌어 그린 크기(world px ÷ 0.1)가 치수(10mm 단위, 최소 100mm, `mmFromBoardRect`), 그린 자리가 평면 배치 위치. 선택·패널·설정·대화·리스트·견적은 보통 사인물과 같습니다. 사진이 없으니 실측 추정·3D·제안 이미지에는 안 나오고(`proposalProblems` 는 사진 없는 사인물을 건너뜀), 리스트 카드는 색 면.
- **연결**: 사진에 영역을 그리고 "기존 사인물과 같은 것?"에서 보드 사인물(목록에 "이름 · 보드")을 고르면 그 영역이 보드 사인물의 규격(치수·종류·디자인)을 쓰고, 보드 사인물 카드와 사진 아래 카드에 ⇄ 가 붙습니다. 리스트·견적에는 하나. 리스트의 [사진에 올리기]도 됩니다.

  - **세 면** (고르기는 대체됨 2026-10-15 → 박스 매니퓰레이터: 정면 축은 사인물 면이 아니라 박스 방향만 바꿈. 면은 구도로 자동)(`faceOf`·`faceFrameOf`, 2026-10-15 사용자: "오직 한쪽면만 기준으로 잡고 있다. 삼면을 구현하지 못한건가?" → "삼면 구조로 진행해줘", "사인물의 정면을 바꾸자는 의미지 기준을 변경하자는 건 아니다"; 같은 날의 "면 방향 자동 인식"(돌출 면만)을 넓힘): 원근 기준(벽면)은 그대로 두고 사인물마다 **정면 축**을 정합니다. 축 이름은 매니퓰레이터 축과 같습니다 — **Y** = 벽 밖을 봄(벽면), **X** = 벽을 따라 봄(벽에 직각인 세로면, 돌출 간판), **Z** = 위·아래를 봄(수평면, 어닝 아랫면 등). 면의 자리는 외곽선에서 **벽에 닿는 변**으로 정합니다(각 꼭짓점의 시선이 벽과 만나는 점의 그 축 값 중, 나머지 꼭짓점이 모두 벽 앞에 오는 값). 네 꼭짓점의 시선이 그 면과 만나는 점이 사인물의 실제 자리이고, 외곽선은 그린 그대로입니다. 면 좌표의 가로·세로는 외곽선 순서(TL→TR, BL→TL)를 따릅니다(돌려 세운 사인물처럼 사진에서 거울상이어도 글자 방향 유지, 3D 는 뒤집어 그림). **자동**(`faceAxis` 없음): 벽면 직사각형이면(비틀림 ≤ 3°) Y, 아니면 X·Z 중 면 위 바른 직사각형으로 폈을 때 꼭짓점이 덜 벗어나는 면(평균이 대각선 5% 안, 사진 px 로 재서 비스듬히 가늘게 보이는 면에서도 손 떨림에 안 흔들림). 어느 면도 아니면 사인물 자신의 면. **고르기**(2026-10-15 사용자: "이동 xyz 끝은 화살표 센터에 투명한 사각형을 위치시킨다 사각 판을 선택하면 그걸 사인물의 정면으로"): 이동 매니퓰레이터의 **두 화살표 사이 반투명 사각 판**(블렌더 평면 핸들처럼, `gizmoOf().planes`: 두 화살표 방향으로 길이의 0.3~0.6). X·Z 사이 판(초록) = 정면 Y(벽면), Y·Z 사이 판(빨강) = 정면 X(세로면), X·Y 사이 판(파랑) = 정면 Z(수평면) — 판 색은 법선 축(= 정면이 되는 축). 지금 정면인 판은 진하게 흰 테두리(`face-axes` `data-axis`, `face-x|y|z` `data-on`·`data-can`). 판을 누르면 그 면이 정면(`SignObject.faceAxis`, 사진마다의 배치라 연결된 사인물에 번지지 않음), 켜진 판을 다시 누르면 자동. 정면으로 찍은 사진에서는 벽에서 나오는 방향이 거의 점이라 X·Y 판·Y·Z 판이 얇게 보입니다(블렌더와 같음). 그 면의 사진일 수 없는 외곽선(예: 정면으로 그린 벽면 직사각형을 X 로)은 흐리게, 누를 수 없음. 3D·흰 상자·**치수 추정**(`faceSizeOf` → `measurePhoto`)이 모두 그 면을 따릅니다. 원근 맞추기 ⊞ 는 Y(벽면) 사인물에만.
- **박스 매니퓰레이터** (원근 설정이 있는 사진, 2026-10-15 사용자: "메니폴레이터는 원근의 값을 기준으로 작동해야한다", "사인물사각툴은 3d가 아니다. 그런척하는 거지 실제가 아니다. 여기에 따라다니는 박스만 3d이다", "박스만 회전하고 크기는 외곽선만", "크기는 각면 중앙과 꼭지에 있어야 한다. 로테이트는 3면 모두에", "새로 생성하는 사인물툴의 메니폴레이터가 엉뚱한곳에 나타나"; 코드 `core/boxGizmo.ts`): **사인물 외곽선은 사진 위 2D**이고 3D 는 외곽선을 따라다니는 **박스뿐**입니다. 매니퓰레이터의 축은 원근 설정의 X(벽 가로)·Y(벽 밖)·Z(위)이고, 자리는 **외곽선 대각선 교점**(`quadCenter`, 평면 직사각형의 원근 중심 — 벽면으로 옮긴 꼭짓점 평균은 외곽선이 벽면이 아니거나 지평선 근처면 엉뚱한 곳이 됐음)입니다. 3D 자리(`anchorOf`)는 그 시선이 사인물 면(어느 면도 아니면 원근 설정의 기준 면)과 만나는 점인데, 기준 면이 바닥(축 X·Y)이고 사인물이 그 지평선 위에 있으면 시선이 카메라 뒤에서 만나 매니퓰레이터가 뜨지 않았습니다(2026-10-15 사용자: "메니폴레이터가 나타나지 않는 사인물이 있다. 핀볼에서 확인해줘" — 핀볼 측사면 2개·측면 1개). 그때는 원점과 같은 깊이에서 카메라를 보는 면에 자리를 잡습니다(축 방향·원근 이동은 그대로). **이동**: X·Y·Z 화살표 = 외곽선을 그 원근 축을 따라(꼭짓점의 3D 자리를 옮겨 다시 사진에, 멀어지면 작아짐 `moveOutline`), 가운데 = 사인물 면 위에서. **정면 단추**(이동 모드에서 모드 단추 아래 X·Y·Z — 외곽선 밑, `face-axes`·`face-x|y|z`; 2026-10-15 사용자: "사인물 정면을 선택하는 것 move일때 하단에 x,y,z 단추로 선택하게 사각은 보이지 않는다" — 화살표 사이 반투명 판은 사진에서 잘 안 보여 대체): 누른 축이 **박스 방향**(`faceAxis`), 지금 축은 흰 테두리. 켜진 단추를 다시 누르면 자동(사인물 면의 법선). **회전**: X·Y·Z 고리 세 개 = **박스 방향만** 그 축 둘레로 돌림(`rotateDir`, 축에서 2° 안이면 붙임, 고리가 선으로 보이면 화면 각) → `boxDir`. **크기**: 네 변 가운데 + 네 꼭짓점 손잡이 8개(`gizmo-size-{sx}_{sy}`) = **외곽선만**, 사인물 면 위에서(`resizeFrameAt`: 변은 그 방향만, 꼭짓점은 비율 유지, 반대쪽은 그대로). 크기 모드에선 꼭짓점 직접 편집 손잡이를 숨깁니다. 판·고리는 외곽선·사인물 면·사인물 크기(`contentSizeOf`)를 바꾸지 않고, 흰 상자와 3D 상자만 그 방향으로 기웁니다(`boxLocalDirOf` → `boxGuideOf(dir)`, `orientBox`). 원근 설정이 없는 사진은 사인물 자신의 면 위 매니퓰레이터(이동·면 안 회전·크기 8개). 예전의 경첩 돌려 세우기 UI(⟂·⇄·▭·초록 손잡이)는 없앴고, 이미 저장된 `turn` 은 그대로 읽습니다.

## 작업 존 (`src/lib/core/zone.ts`, 2026-10-13 사용자 요청)
- 사진마다 **실제 작업할 벽면 영역**을 다각형으로 표시합니다(`Photo.zones`, 사진 px, 정수. 옛 데이터의 `zone` 하나도 `zonesOf()`로 읽음). 존 밖은 어둡게 처리됩니다.
- 만들기: 존 도구(Z 또는 ▱ 존) → 사진 위 드래그 → 사각형 존이 **추가**됩니다(사진당 여러 개, 예: 정면 벽 + 옆면 벽). 라벨은 "작업 존 1, 2…".
- 편집(편집 권한): 존을 선택하면 꼭짓점 핸들(○)과 **변 중간 핸들(□)**이 보입니다. 중간 핸들을 누르면 그 자리에 꼭짓점이 추가되고, 꼭짓점을 눌러 선택한 뒤 **Delete/Backspace**로 지웁니다(3개 미만으로는 줄지 않음). 꼭짓점 선택 없이 존만 선택한 채 Delete 를 누르면 **그 존이 삭제**됩니다. 꼭짓점은 드래그로 이동. 모두 ⌘Z 로 되돌릴 수 있습니다.
- 고객(viewer)은 존을 보지만 핸들은 없습니다.
- **목적**: AI 자동 분리가 존 안에만 집중하게 하는 것 → [auto-segment.md](auto-segment.md). 존마다 따로 분석하고, 존을 바꾸면 다시 분석합니다.
- 다음 단계 후보: 존의 실제 가로·세로(mm)를 넣어 실측 기준으로 쓰기, 5차 실사 합성의 벽면 기준, 다각형 사인물에 같은 꼭짓점 편집 적용.

사용자: "핀치줌 안되는거 해결… 텍스트도 자리가 넘치거나 모자란데 단축어로 표시".

- **패널·창**: 사인물 패널·견적 패널은 화면 아래 시트(높이 62%/55%), 3D 뷰·원근 창은 전체 화면(원근 창은 사진 위·설정 아래 세로 배치), `.grid2` 는 한 칸. 키보드가 올라오면 화면이 줄어들도록 `interactive-widget=resizes-content`, 높이는 `100dvh`.
- **빠른 막대**(`QuickBar.svelte`, `quick-bar`, 2026-10-15 사용자: "모바일에서는 사인물을 선택하면 하단에 1개의 셀렉터(종류 선택), 2개의 버튼 간단 입력(사인물 네임, 사이즈), 상세정보를 둔다"; 배경 2026-10-14: "현장에서는 모바일로 간단하게 치수만 입력하고 데스크톱에서 현재 시스템을 사용"): 휴대폰 폭에서 사인물을 선택하면 전체 패널 대신 아래 막대 — **종류 셀렉터**(`quick-kind`: **간판 / 스카시 / 시트** 분류만 — 2026-10-15 사용자 "현재 내역(제품 목록)은 간판 상세에" — 패널과 같은 규칙으로 처음 선택은 바로, 이후 변경은 확인 `category-confirm`; 현재 제품·시트 이름은 아래 힌트 `quick-detail`, 세부 종류·옵션은 [상세정보] → 설정), **[이름]**(`quick-name` → 아래 줄 입력 `quick-name-input`, Enter/blur 저장), **[사이즈]**(`quick-size`, 현재 치수 또는 ≈추정 표시 → 아래 줄 가로×세로 mm `quick-width/-height` 숫자 키패드 + 같은 사진의 이전/다음 사인물 `quick-prev/-next`, n/N, 순서는 `app.photoSigns` = 왼쪽부터), **[상세정보]**(`quick-panel-open` → `app.panelOpen`, 전체 패널을 시트로; 패널 ✕는 선택을 유지한 채 막대로 복귀). 사진 **머리글(이름)을 탭**하면 그 사진의 첫 사인물이 선택되어 바로 입력 흐름이 시작됩니다(`PhotoZone ontap`, 끌면 이동·탭이면 선택). 데스크톱은 그대로 패널.

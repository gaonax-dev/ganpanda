# 사인물 리스트(전개도)와 견적

## 요약
모든 사인물을 원근 보정해 **실제 mm 축척**으로 펼친 무한 캔버스입니다. 견적은 여기서 산출합니다. 2차(2026-10-13)에서 단가표·견적 규칙·견적서 출력이 들어갔습니다.

## 상태
구현됨.

## 전개도 규칙
- world 1 = 1mm. 각 사인물 = 가로×세로 mm 크기의 카드. 사진 영역을 `cssMatrix3d(quadToRect(...))`로 정면 보정해 보여 줍니다. 원형은 타원으로, 다각형은 윤곽으로 잘라 냅니다.
- 둥근 사각(`corner`)은 `inset(0 round r)`로 잘라 보여 주고, 면적은 모서리를 깎은 값(w·h−(4−π)r²) → [photo-board.md](photo-board.md)
- **여러 사진에 표시된 같은 사인물은 하나**(원본)만 나옵니다. 연결된 영역(`sameAs`)은 전개도·견적·견적서·UV 목록에서 제외 → `app.signs`. → [photo-board.md](photo-board.md) "여러 사진의 같은 사인물"
- 치수(입력 또는 추정)가 없는 사인물은 전개도에서 빠지고 "치수 필요" 목록에 나옵니다. 누르면 사진 보드로 이동합니다.
- 위치: 끌어서 옮기면 `listX/listY`에 저장. 없으면 자동 배치(선반 방식, 간격 600mm, 줄 폭 12,000mm, `layout.ts`).

## 단가표 (2-1, `src/lib/core/pricing.ts`)
- `PriceTable`: 제품 단가(보드 원/㎡, 채널 원/자·cm), 시트 단가(원/㎡), 기본 설치·운반비, 항목 최소 금액, 반올림 단위(1·10·100·1,000·10,000), 부가세 포함 여부. 카탈로그(`catalog.ts`)는 이름·단위만 갖습니다.
- **저장 위치**: 프로젝트 문서 `settings.prices` → 고객(viewer)도 같은 단가로 봅니다. 소유자가 프로젝트를 열었을 때 문서에 단가표가 없으면 **계정 기본값**(`/api/me/prices`, 없으면 예시값 `DEFAULT_PRICES`)을 복사해 넣습니다.
- 편집: 사인물 리스트 → [단가 설정](편집 권한). 입력 즉시 프로젝트에 반영. 소유자는 [내 기본 단가로 저장]으로 계정에 저장(새 프로젝트에 적용).
- 저장값 합치기(`mergePrices`): 모르는 키·음수·잘못된 반올림 단위는 버리고 기본값 유지. 0 은 허용(설치비 없음).

## 견적 규칙 (2-2, `src/lib/core/quote.ts`)
| 항목 | 계산 |
|---|---|
| 보드 | 외곽 직사각형 면적(㎡) × ㎡ 단가 |
| 채널 | 글자수 × 글자 높이(cm) × 자당 단가. **글자수 = 수동 입력 > 문구(`text`)에서 공백·줄바꿈 제외**. 둘 다 없으면 "문구 또는 글자수 필요" |
| 시트 | 실제 도형 면적(사각 w×h, 원 π/4·w·h, 다각형 정면 보정 면적) × ㎡ 단가 |
| 항목 금액 | 반올림 단위 적용 후 최소 금액 미만이면 최소 금액(상세에 "최소 … 적용") |
| 설치·운반비 | 프로젝트 설정 `installFee`(없으면 단가표 기본값). 0 가능 |
| 추가 항목 | `settings.extras[{label, amount}]`, 할인은 음수 |
| 공급가 | 항목 합계 + 설치비 + 추가 항목 |
| 부가세 | 별도: 공급가 × 10%, 합계 = 공급가 + 부가세 / **포함**: 합계 = 공급가, 부가세는 역산 안내 |
- 치수가 없는 사인물은 추정 치수로 계산하고 "추정"으로 표시합니다. 치수·추정 둘 다 없으면 0원 + "치수 필요".

## 견적서 (2-3, `src/lib/ui/QuoteSheet.svelte`)
- [견적서] 버튼 → A4 양식 오버레이(프로젝트명·작성일·작성자, 항목별 규격·산출·금액, 설치비·추가 항목, 공급가·부가세·합계, 문구 표기). [인쇄 · PDF 저장]은 브라우저 인쇄.
- 고객(viewer)도 볼 수 있습니다. 작성자 사업자 정보(상호·연락처·계좌)는 남은 일.

# 사인물 리스트(전개도)와 견적

## 요약
모든 사인물을 원근 보정해 **실제 mm 축척**으로 펼친 무한 캔버스입니다. 견적은 여기서 산출합니다. 2차(2026-10-13)에서 단가표·견적 규칙·견적서 출력이 들어갔습니다.

## 상태
구현됨.

## 전개도 규칙
- world 1 = 1mm. 각 사인물 = 가로×세로 mm 크기의 카드. 사진 영역을 `cssMatrix3d(quadToRect(...))`로 정면 보정해 보여 줍니다. 원형은 타원으로, 다각형은 윤곽으로 잘라 냅니다.
- 둥근 사각(`corner`)은 `inset(0 round r)`로 잘라 보여 주고, 면적은 모서리를 깎은 값(w·h−(4−π)r²) → [photo-board.md](photo-board.md)
- **여러 사진에 표시된 같은 사인물은 하나**(원본)만 나옵니다. 연결된 영역(`sameAs`)은 전개도·견적·견적서·UV 목록에서 제외 → `app.signs`. → [photo-board.md](photo-board.md) "여러 사진의 같은 사인물"
- 치수(입력 또는 추정)가 없는 사인물은 전개도에서 빠지고 "치수 필요" 목록에 나옵니다. 누르면 사진 보드로 이동합니다.
- 위치: 끌어서 옮기면 `listX/listY`에 저장. 없으면 자동 배치(선반 방식, 간격 600mm, 줄 폭 12,000mm, `layout.ts`). **보드의 평면 구역과 같은 목록·배치**(`app.flatCards/flatPlaced`, 2026-10-15) — 어느 쪽에서 끌어도 둘 다 바뀜.

## PDF (전개도 → SVG → 인쇄, 2026-10-15)
사용자: "리스트 뷰는 최종 출력에 사용될 것이다. 최종 출력에 사용되기 전에 svg 를 사용해 사인물을 pdf 로 작성한다". 견적 패널의 **[PDF]**(`export-pdf`): 전개도를 `core/listSvg.ts` `listSvg()` 로 **SVG** 로 그립니다 — A4 가로(297×210mm) 한 장에 전부 들어가는 축척(실물보다 크게는 안 함, "축척 1:n" 표기), 카드마다 사각(둥근 모서리)·입힌 디자인 이미지(data URL, clipPath)·위·옆 치수선(mm, 추정 표시)·이름·종류(몸통+채널+시트)·옵션·문구·두께·금액, 제목(프로젝트명)·날짜·합계. 배치는 리스트 뷰 그대로(`listX/listY`). 새 창에 SVG 를 띄우고 인쇄 대화상자(A4 가로, 여백 0) → 브라우저의 "PDF 로 저장". 팝업이 막히면 안내. 단위 테스트 `tests/unit/listSvg.test.ts`, E2E `tests/e2e/boardCards.spec.ts`. 후속: 여러 장 나눔, 치수 글자 크기 옵션.

## SVG 내려받기 — 일러스트레이터 (2026-10-17)
사용자: "리스트가 일러스트로 내보내기 되는가?" → "비율, 윤곽선은 옵션으로". 견적 패널 **[SVG]**(`export-svg`) → 옵션 패널(`svg-options`) → [내려받기](`svg-download`)로 `.svg` 파일. 같은 `listSvg()` 라 PDF 와 내용이 같고, 일러스트레이터에서 열면 치수가 mm 그대로(viewBox = 용지 mm).
- **비율**: 실물 **1:1**(`svg-scale-1`, 기본 — 제작 도면, 카드가 실제 mm, 용지는 내용 + 여백·라벨 크기) / **1:10**(`svg-scale-10`, 큰 간판 — 일러 아트보드 한계 약 5.8m) / **A4 맞춤**(`svg-scale-a4`, PDF 와 같은 모양). `SvgSheet.scale`.
- **글자 윤곽선**(`svg-outline`, 기본 켬): 모든 글자(제목·치수·라벨·구성 요소 글자)를 Pretendard Bold 로 `<path>` 로 바꿈 — 폰트가 없는 컴퓨터에서도 같은 모양, 대신 글자 편집 불가. 끄면 `<text>`(글꼴 대체될 수 있음). `core/svgText.ts` `outlineRenderer(font)`(opentype.js `getPath`, 정렬·기준선·폭 맞춤을 `<text>` 와 같게), `SvgSheet.text`.
- **대지 레이어**(2026-10-18 사용자: "현재 사인물을 대지별로 담아서 일러스트로 저장하면 해당 일러스트에서 대지별로 내보내기 할 수 있다 … 현재 구성한 레이아웃이 유지되어야 한다"): 내려받는 SVG 에 `<g id="대지">` 레이어로 사인물마다 **같은 자리의 보이지 않는 사각형**(`data-artboard`, fill·stroke 없음)이 들어 있다(`listSvg({artboards:true})`). 일러스트레이터에서 레이어 **대지**를 선택 → **오브젝트 › 대지 › 선택 오브젝트를 대지로 변환** 하면 지금 배치 그대로 사인물마다 대지가 되어 대지별 내보내기를 쓸 수 있다(옵션 패널 `svg-artboards-tip`). 페이지를 나누는 PDF 방식은 배치가 깨져 쓰지 않는다.
- **그림 묻기**(2026-10-18 사용자: "svg를 내보내기하고 나면 일러스트에서 [연결 패널에서 일부 파일이 누락되거나 수정되었습니다] 안내가 나온다"): 입힌 디자인·구성 요소 그림은 `<image>` 에 **`xlink:href` 와 `href` 둘 다**로 쓴다 — 일러스트레이터는 SVG 2 의 `href` 만 있으면 그림을 못 읽고 연결 파일 누락으로 본다. 값은 항상 **그림 MIME 의 data URL**(`core/imageData.ts` `imageDataUrl`: 바이트 머리로 PNG/JPEG/WebP/GIF/SVG 를 정해 blob 의 type 이 비거나 octet-stream 이어도 그림으로), 못 만들면(받기 실패·그림 아님) 그 그림은 빼고 "그림 n개를 SVG 에 묻지 못해 뺐습니다" 알림 — 전엔 실패하면 blob:/http 주소를 그대로 넣어 누락 연결이 됐다.
- 파일 이름 `<프로젝트> 전개도 1-1.svg` 등. `app.lastSvg` 에 마지막 SVG. 테스트: `tests/unit/listSvg.test.ts`(비율·윤곽선·xlink), `tests/unit/imageData.test.ts`, `tests/e2e/boardCards.spec.ts`.

## 견적 규칙 (2-2, `src/lib/core/quote.ts`)
| 항목 | 계산 |
|---|---|
| 보드 | 외곽 직사각형 면적(㎡) × ㎡ 단가 |
| 채널 (옵션) | 몸통 줄과 별도로 한 줄 더: 글자수 × 글자 높이(cm, 옵션 `chHeight` 없으면 간판 높이) × 자당 단가. **글자수 = 수동 입력 > 문구(`text`)에서 공백·줄바꿈 제외**. 둘 다 없으면 "문구 또는 글자수 필요" |
| 시트 | 실제 도형 면적(사각 w×h, 원 π/4·w·h, 다각형 정면 보정 면적) × ㎡ 단가 |
| 항목 금액 | 반올림 단위 적용 후 최소 금액 미만이면 최소 금액(상세에 "최소 … 적용") |
| 설치·운반비 | 프로젝트 설정 `installFee`(없으면 단가표 기본값). 0 가능 |
| 추가 항목 | `settings.extras[{label, amount}]`, 할인은 음수 |
| 공급가 | 항목 합계 + 설치비 + 추가 항목 |
| 부가세 | 별도: 공급가 × 10%, 합계 = 공급가 + 부가세 / **포함**: 합계 = 공급가, 부가세는 역산 안내 |
- 치수가 없는 사인물은 추정 치수로 계산하고 "추정"으로 표시합니다. 치수·추정 둘 다 없으면 0원 + "치수 필요".

## 줄 금액 수동 입력 · 자동 전환 (2026-10-16)
사용자: "사인물 견적서는 수동으로 입력되어야한다. 수동입력후 자동전환버튼 / 해당 목록을 선택하면 구성품들과 단가연결 해당 품목 / 단가 연결이 공급사 금액" → "원가와 판매가로 이익율이 확인되어야한다. 오너와 맴버(허가시)에게만보이게 맴버의 경우 손해인 상태를 표시".
- 줄마다 고정 키(`QuoteLine.key`: `<사인물>:body` · `:part:<구성 요소>` · `:top` · `:sheet:<시트>`). 프로젝트 설정 `lineAmounts[키]` = 수동 금액(숫자) 또는 `'auto'`.
- `settings.quoteMode`: **새 프로젝트는 `manual`**(소유자가 처음 열 때 단가표와 함께 넣음) — 금액을 넣기 전 줄은 0원·"금액 입력"(`line-amount` 비어 있음), 아래 "금액을 넣지 않은 줄 n건"(`quote-needs-input`). 값이 없는 **기존 프로젝트는 `auto`**(지금처럼 계산, 고객에게 보낸 금액이 바뀌지 않게).
- 줄의 금액 칸에 입력 = 수동, [자동](`line-auto`) = 단가표·계산법 금액(`QuoteLine.auto`)으로, 자동 줄은 "자동" 표시(`line-is-auto`). 위 "전체 자동 금액으로"(`quote-auto-all`) = 지금 줄을 모두 자동. 칸을 비우면 프로젝트 기본.
- 견적서·제안·계약 금액(프로젝트 목록 `quoteTotal`)은 이렇게 정해진 금액을 씁니다.

## 원가 · 이익율 (2026-10-16)
- **원가 = 공급사 금액(배수 전)**: 공급 품목 연결이면 수량 × 공급 단가, 계산법이면 계산법 금액. 직접 입력 단가 줄은 원가 없음(합계에서 빼고 "원가 없는 줄 n건").
- 줄: `원가 ○원 · 이익율 ○%`(`line-margin`), 판매가 < 원가면 줄을 붉게 + **손해**(`line-loss`). 합계(`quote-margin`): 원가·이익·이익율, 손해면 **손해**(`quote-loss`).
- 줄을 누르면(`line-open`) 그 사인물의 **구성품 표**(`line-parts`): 구성품 · 단가 연결(공급업체 계산법/품목, 없으면 직접 입력) · 공급사 금액 · 판매가 · 이익율.
- **보이는 사람**: 오너 = 원가 금액·이익·이익율. **멤버(허가)** = 설정의 팀 멤버 중 "정산 보기"를 켠 사람이 편집 초대로 들어온 경우(`/access` 의 `billing`) — 이익율과 손해 표시만(원가 금액은 안 보임). 그 밖의 편집자에게는 안 보임. 고객(viewer)은 사인물 리스트 자체가 없음(사진 보드만).
- 주의: 단가표(공급 연결 포함)는 프로젝트 문서에 있어 기술적으로 숨겨진 값은 아닙니다(화면에서만 가림). 원가를 서버에서 감추려면 단가표를 문서 밖(계정)으로 옮겨야 합니다 — 계획.

## 치수 없는 사인물의 카드 (2026-10-22)
사용자: "사인물이 사이즈를 넣지 않으면 사인물 카드로 나오지 않는다". 치수(입력·추정)가 없는 사인물도 보드 평면 구역·리스트에 **임시 크기 카드**로 나온다(`core/boardCards.ts placeholderSize`: 사진 영역 비율로 가로 1000mm, 영역이 없으면 1000×600) — 카드에 **"치수 없음"** 배지(`card-unsized`·`list-unsized`), 금액 대신 "치수 없음". 임시 카드는 **견적·PDF·SVG 에 들어가지 않는다**(`exportable` = 치수 있는 것만; 견적은 전부터 `sizeOf` 기준). 치수를 넣으면 실측 카드로 바뀐다. 테스트 `tests/e2e/unsizedCard.spec.ts`.

# 사인물 리스트(전개도)와 견적

## 요약
모든 사인물을 원근 보정해 **실제 mm 축척**으로 펼친 무한 캔버스입니다. 견적은 여기서 산출합니다.

## 상태
구현됨 (예시 단가). 자동 견적 고도화는 2차 → [../product/roadmap.md](../product/roadmap.md)

## 전개도 규칙
- world 1 = 1mm. 각 사인물 = 가로×세로 mm 크기의 카드. 사진 영역을 `cssMatrix3d(quadToRect(...))`로 정면 보정해 보여 줍니다. 원형은 타원으로, 다각형은 윤곽으로 잘라 냅니다.
- 치수(입력 또는 추정)가 없는 사인물은 전개도에서 빠지고 "치수 필요" 목록에 나옵니다. 누르면 사진 보드로 이동합니다.
- 위치: 끌어서 옮기면 `listX/listY`에 저장합니다. 위치가 없으면 자동 배치(선반 방식, 간격 600mm, 줄 폭 12,000mm, `layout.ts`)합니다.
- 치수선과 사양 카드는 확대 배율과 관계없이 같은 글자 크기로 보입니다.

## 견적 규칙 (`src/lib/core/quote.ts`)
| 항목 | 계산 |
|---|---|
| 보드 | 외곽 직사각형 면적(㎡) × ㎡당 단가 |
| 채널 | 글자수 × 글자 높이(cm) × 자당 cm 단가. 글자수가 없으면 0원 + "글자수 필요" |
| 시트 | **실제 도형 면적**(㎡) × ㎡당 단가. 사각 = 가로×세로, 원형 = π/4 × 가로×세로, 다각형 = 정면 보정 후 면적 |
| 치수 없음 | 0원 + "치수 필요" |
| 부가세 | 공급가 × 10% (`VAT_RATE`) |

## 카탈로그 (`src/lib/core/catalog.ts`, 예시 단가)

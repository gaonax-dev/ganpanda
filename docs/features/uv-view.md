# UV 뷰 (디자인 소스 매핑)

## 상태
계획 — 화면 자리(`src/lib/views/UvView.svelte`)만 있습니다. 3차 → [../product/roadmap.md](../product/roadmap.md)

## 목표 (사용자 요구)
- 디자인 파일을 받아 오브젝트에 표시합니다. **한 파일에 이미지가 여러 개** 있을 수 있습니다.
- UV 뷰를 띄우고, 파일 속 이미지를 고른 뒤 오브젝트 면에 위치시킵니다.
- **일러스트레이터(.ai) 파일을 직접 이미지 소스로 변환**하고, **소스 히스토리**(버전 기록)를 남깁니다.

## 설계 메모 (미확정)
- 오브젝트 면은 정면 직사각형(mm)으로 다루고, 사진 위에는 `rectToQuad`로 원근을 입혀 표시합니다.
- 에셋은 내용 해시로 저장되므로, 소스 버전마다 다른 에셋 ID가 됩니다. 히스토리는 오브젝트에 (에셋 ID, 잘라낸 영역, 시각, 작성자) 목록으로 남기는 방식이 자연스럽습니다.

# UV 뷰 (디자인 소스 매핑)

## 요약
디자인 파일을 올리면 아트보드(페이지)마다 이미지가 되고, 사인물을 고른 뒤 페이지 위에 **잘라낼 영역**을 그리면 그 부분이 사인물 면에 입혀집니다. 변경 이력은 사인물마다 남고 되돌릴 수 있습니다.

## 상태
구현됨 (3차, 2026-10-13).

## 파일 변환 (`src/lib/design/convert.ts`)
| 파일 | 처리 |
|---|---|
| `.ai` (일러스트레이터) | **PDF 호환으로 저장된 파일만** 읽습니다(파일 앞부분에 `%PDF`). 아니면 "PDF 호환 파일 만들기를 켜고 다시 저장" 안내. 아트보드 = 페이지 |
| `.pdf` | 페이지마다 이미지 |
| `.svg` `.png` `.jpg` `.webp` | 한 페이지 |
- pdf.js(`pdfjs-dist`, 워커는 번들 에셋)로 브라우저에서 그립니다. 긴 변 2048px(`PAGE_MAX_SIDE`)로 줄이고 흰 배경 PNG 로 저장. 외부 서버 없음.
- 원본 파일도 에셋으로 저장(`fileAssetId`) — 재변환·이력용. 모두 소유 계정 용량에 합산.

## 데이터
- `sources`(문서): `{ id, name, kind, fileAssetId, pages[{assetId, w, h}], author, createdAt }` → [../architecture/data-model.md](../architecture/data-model.md)
- 사인물 `design`: `{ sourceId, page, crop{x,y,w,h}(페이지 px) }`, `designHistory`: 최신이 앞, 최대 20개(`HISTORY_MAX`), 직전과 같으면 추가 안 함.
- 소스를 지우면 그 소스를 쓰던 사인물의 `design`은 풀리고 이력은 남습니다.

## 화면
- UV 뷰(무한 캔버스): 소스마다 한 줄, 페이지는 가로로. 오른쪽에 사인물 목록(`uv-object`)과 선택한 사인물의 **소스 히스토리**(누르면 그 상태로 복원 = 새 이력 추가), [디자인 떼기].
- 선택 해제: 빈 곳 클릭, 목록의 같은 사인물 다시 클릭, Esc (2026-10-14 버그 수정: 선택 강조 상자가 사라지지 않던 문제). 연결된 영역(`sameAs`)의 잘라낸 영역은 원본 것만 표시.
- 영역 그리기(편집 권한): 사인물 선택 → 페이지 위 드래그. 페이지 밖은 잘리고 8px 미만은 무시(`normalizeCrop`). 라벨의 [전체 입히기]로 페이지 전체.
- 표시: 사진 보드에서는 잘라낸 영역을 사인물 원근 사각형에 `matrix3d`로 변형해 올리고(원형·다각형은 clip-path), 전개도에서는 카드 크기에 맞춰 늘립니다(`DesignFace.svelte`). 고객(viewer)도 봅니다.
- 실행 취소: `design` 변경은 사인물 변경이라 ⌘Z 로 되돌아갑니다(소스 추가·삭제는 아님).
